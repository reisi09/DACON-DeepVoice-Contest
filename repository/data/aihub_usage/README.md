# AI-Hub 데이터 사용 기록 (출처 표기)

본 프로젝트는 과학기술정보통신부·한국지능정보사회진흥원(NIA)의 **AI 허브(aihub.or.kr)** 데이터를 활용했다.
원본 음원·파생 특징·파생 채널 프로필은 AI-Hub 이용약관(해외 반출 금지, 제3자 제공 금지)에 따라 이 저장소에 없다.
모든 처리는 국내 로컬 장비(Apple Silicon)에서만 수행했고, 해외 클라우드(VESSL)로 보낸 적이 없다.

## 이용 조건 준수
- 제3자 제공·해외 반출 없음: 원본·특징 캐시는 로컬에만 있다 (`_workspace/aihub`, `_workspace/s2_extra`, `_workspace/aihub_probe`).
- 화자 재식별·음성 복제 없음: AI-Hub 화자 음성으로 TTS/VC를 만들지 않았다.
- 학습된 모델(2차 저작물)은 AI-Hub 정책상 출처 표기 조건으로 활용 가능하다 (DACON 답변 417844: 사용 가능).
