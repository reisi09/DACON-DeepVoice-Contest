  - heading "2. 대회 규칙" [level=3]:
    - strong: 2. 대회 규칙
  - paragraph:
    - strong: 1) 사용에 법적 제한이 없는 모든 방법론 가능
  - list:
    - listitem: • 아래 규정을 준수하는 범위 내에서, 누구나 접근 가능한 공개 자원이며 최소 비영리 목적으로의 사용이 허용된 경우 사전학습 모델, API, 외부 데이터 수집·생성 등 모든 방법론을 활용할 수 있습니다.
    - listitem: • 단, 사용하려는 데이터, 사전학습 모델, API 등의 라이선스 및 이용조건을 참가자가 직접 확인하고 준수해야 합니다.
  - paragraph:
    - strong: 2) 출처 명시 의무
  - list:
    - listitem: • 2차 평가 자료 제출 시 본 규정에 따라 사용된 모든 요소에 대한 각각의 출처를 명확하게 기술할 수 있어야합니다.
  - paragraph:
    - strong: 3) 비공개 평가 데이터를 활용한 추가 학습 금지
  - list:
    - listitem: • 제출하는 추론 코드에서는 예측을 위한 전처리·후처리 및 추론 과정은 자유롭게 구성할 수 있습니다.
    - listitem: • 다만, 비공개 평가 데이터셋을 활용한 추가 학습, 모델 튜닝, Pseudo-Labeling 등 모델을 갱신하거나 학습에 활용하는 행위는 허용되지 않습니다.
  - paragraph:
    - strong: 4) 비공개 평가 데이터의 파일 단위 독립 예측 원칙
  - list:
    - listitem: • 비공개 평가 데이터의 각 파일 샘플은 서로 독립적으로 예측해야 합니다.
  - paragraph:
    - strong: "허용:"
    - text: 하나의 파일 샘플을 세그먼트 단위로 분할하여 추론하고, 결과를 종합하는 방식은 허용됩니다.
  - paragraph:
    - strong: "금지:"
    - text: 다른 파일 샘플의 정보·예측값·통계 등을 활용하여 예측값을 생성하거나 보정하는 방식은 허용되지 않습니다.
