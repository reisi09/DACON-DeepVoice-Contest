  - heading "1. 리더보드 산식" [level=3]:
    - strong: 1. 리더보드 산식
  - list:
    - listitem: "• 평가 산식 : 평가 지표는 ADS(AI-Generated Audio Detection Score)와 CPS(Component Presence Score)의 가중합"
  - paragraph:
    - strong: Score(총점, ↑) = 0.9 X ADS + 0.1 X CPS
  - list:
    - listitem: • ADS(AI-Generated Audio Detection Score, AI 생성 오디오 탐지 점수)
    - listitem: • ADS = 0.5 X (1 - File EER, 파일 단위 탐지) + 0.2 X (1 - Voice EER, 음성 성분 단위 탐지) + 0.3 X (1 - Music EER, 음악 성분 단위 탐지)
    - listitem: • CPS(Component Presence Score, 구성 요소 존재 여부 판별 점수)
    - listitem: • CPS = 0.5 X (Voice Presence ROC-AUC, 음성 성분 검출) + 0.5 X (Music Presence ROC-AUC, 음악 성분 검출)
  - text: fpr, tpr, _ = roc_curve(y_true, y_score, pos_label=1, drop_intermediate=False)
  - text: fnr = 1 - tpr
  - text: idx = np.argmin(np.abs(fpr - fnr))
  - text: EER = (fpr[idx] + fnr[idx]) / 2
  - paragraph: ※ FAKE를 양성 클래스(1)로 정의합니다.
  - paragraph: ※ Voice EER은 음성이 존재하는 샘플에서만, Music EER은 음악이 존재하는 샘플에서만 계산됩니다.
  - paragraph: ※ 최종 평가는 총점(Score)을 기준으로 평가됩니다.
  - list:
    - listitem: "• Public Score : 전체 테스트 데이터 100%"
    - listitem: "• Private Score : 대회 종료 시점의 Public Score"
  - paragraph
  - heading "2. 평가 기준" [level=3]:
    - strong: 2. 평가 기준
  - list:
    - listitem: "• 1차 평가 : Private Score (대회 종료 시점의 Public Score)"
    - listitem: "• 2차 평가 : 2차 평가 자료를 제출하고 검증을 통과한 1차 평가 점수 기준 상위 15팀에 대한 종합 평가 진행"
    - listitem: • 2차 평가 항목
  - paragraph:
  - paragraph: ※ 종합 평가는 전문 심사위원단의 서면 평가로 진행
  - paragraph: "※ 모델 성능(30점) 환산식 : 30 X ((2차 평가 대상팀 리더보드 Public 점수) / (2차 평가 대상팀 중 리더보드 Public 최고점수))^N (N은 조정 계수로 1~5 사이로 설정되며 비공개)"

  - paragraph: 📁 제출 파일 구조 (submit.zip)
  - text: submit.zip
  - text: "├── model/ # 모델 가중치 파일을 저장하는 디렉토리"
  - text: "│ └── (예: model.pt 등)"
  - text: "├── script.py # 실제 추론이 수행되는 실행 코드"
  - text: "└── requirements.txt # 필요한 패키지 및 버전 명시"
  - list:
    - text: •
    - code: script.py
    - text: 는 submit.zip을 제출 시 평가 서버에서 자동으로 실행됩니다.
    - text: •
    - code: requirements.txt
    - text: 는
    - code: pip install -r requirements.txt
    - text: 명령어로 설치 가능한 형태여야 하며, 추론 시 필요한 모든 패키지를 포함해야 합니다.
    - listitem: • submit.zip 내 구조는 반드시 일치해야하며, 추가 최상위 폴더가 zip 구조 내 존재하는 경우 등 구조가 불일치하는 경우 설치 오류가 발생합니다.

  - text: "├── data/ # 평가에 사용될 테스트 데이터 (디렉토리 자동 생성)"
  - text: "└── output/submission.csv # 참가자 추론 결과가 저장되는 경로 (디렉토리 자동 생성)"
  - list:
    - text: •
    - code: data/
    - text: 디렉토리는 실제 평가 데이터를 포함한 경진대회 데이터가 포함되며, 읽기전용으로 쓰기 및 수정이 불가능한 디렉토리입니다.
    - text: •
    - code: output/
    - text: 디렉토리는 참가자의
    - code: script.py
    - text: 실행 결과로 생성된 예측 결과 파일이 저장되는 디렉토리이며, 해당 디렉토리 내에 반드시
    - code: submission.csv
    - text: 으로 생성될 수 있어야합니다.
