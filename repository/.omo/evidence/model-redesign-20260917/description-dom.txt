  - heading "[배경]" [level=3]:
    - strong: "[배경]"
  - paragraph: 생성형 인공지능과 음성합성 기술의 고도화로 실제 음성과 구분하기 어려운 딥보이스의 생성·활용이 확산되고 있습니다. 딥보이스가 보이스피싱, 음성 사칭 및 허위정보 생성 등에 악용됨에 따라, 다양한 생성기술과 실제 통신환경에서 발생하는 음성 변형에 대응할 수 있는 탐지 기술의 중요성이 높아지고 있습니다.
  - paragraph: 또한 생성형 AI를 활용한 음성뿐만 아니라 음악 등 다양한 형태의 오디오 생성·변조가 가능해짐에 따라, 딥보이스 탐지 역시 다양한 오디오 환경을 종합적으로 고려할 필요가 있습니다. 특히 하나의 오디오에 음성 또는 음악이 단독으로 존재하거나 함께 포함될 수 있는 환경에서, 각 유형의 존재 여부와 생성·변조 여부를 정확하게 판별할 수 있는 탐지 기술이 요구되고 있습니다.
  - paragraph
  - heading "[대회 방식]" [level=3]:
    - strong: "[대회 방식]"

  - paragraph: "🔹2차 평가: 진출팀은 '모델 개발 보고서'와 '학습데이터 구성 보고서'를 작성하여 제출해야 하며, 이를 종합적으로 평가하여 최종 상위 7팀을 수상팀으로 선정합니다."

  - heading "[설명]" [level=3]:
    - strong: "[설명]"
  - paragraph: 본 대회는 오디오에 포함된 음성·음악의 존재 여부와 각 성분이 AI를 통해 생성되었는지를 탐지하는 문제입니다.
  - paragraph
  - paragraph:
    - strong: 1. 평가 데이터 구성
  - list:
    - listitem: • 평가 데이터는 총 1,200개의 오디오 파일로 구성됩니다.
    - listitem: • 각 파일의 길이는 4초 이상 1분 이하입니다.
    - listitem: • 모든 오디오 파일은 16 kHz 샘플링레이트로 표준화되어 있습니다. 채널은 샘플 별로 모노/스테레오 모두 존재합니다.
    - listitem: • 개발 모델은 MP3, WAV, FLAC 등 다양한 오디오 확장자를 입력으로 처리할 수 있도록 구현해야 하며, 평가 데이터도 다양한 오디오 확장자로 구성되어 있습니다.
    - listitem: • 일부 샘플에는 전화채널 오디오가 포함되어 있습니다.
  - paragraph
  - paragraph:
    - strong: 2. 오디오 유형
  - list:
    - text: •
    - strong: 음성
    - text: ": 사람의 발화 또는 보컬만 포함된 오디오"
    - text: •
    - strong: 음악
    - text: ": 보컬이 없는 반주·악기음만 포함된 오디오"
    - text: •
    - strong: 혼합
    - text: ": 음성과 음악이 동시에 또는 순차적으로 포함된 오디오"
  - paragraph: (*) 보컬은 음성 성분으로 분류합니다. 따라서 보컬과 반주가 함께 포함된 노래는 혼합 오디오에 해당합니다.
  - paragraph
  - paragraph:
    - strong: 3. Real(0)·Fake(1) 기준
  - list:
    - text: • AI를 통해 생성된 음성 또는 음악 성분은
    - strong: FAKE
    - text: 로 분류합니다.
    - text: • AI를 통해 생성되지 않은 실제 원천의 음성 또는 음악 성분은
    - strong: REAL
    - text: 로 분류합니다.
    - text: • 음성과 음악 중 하나라도 FAKE이면 파일 전체를
    - strong: FAKE
    - text: 로 분류합니다.
    - text: • 실제 원천 오디오에 품질 개선, 잡음 제거, 음량 조정 등 음성·음악 성분 자체를 새로 생성하지 않는 후처리만 적용된 경우에는
    - strong: REAL
    - text: 로 간주합니다.
  - paragraph
  - paragraph:
    - strong: 4. 예측 항목
  - paragraph: 참가자는 입력 오디오 파일마다 다음 5개의 각각 0~1 사이의 확률을 예측해야 합니다.
  - list:
    - text: •
    - code: FILE_FAKE_PROB
    - text: ": 파일 전체가 FAKE일 확률"
    - text: •
    - code: VOICE_FAKE_PROB
    - text: ": 음성 성분이 FAKE일 확률"
    - text: •
    - code: MUSIC_FAKE_PROB
    - text: ": 음악 성분이 FAKE일 확률"
    - text: •
    - code: VOICE_PRESENT_PROB
    - text: ": 음성이 존재할 확률"
    - text: •
    - code: MUSIC_PRESENT_PROB
    - text: ": 음악이 존재할 확률"
