# Experiment notebook implementation contract

Scope: produce a portable H100 experiment notebook implementing the reviewed design's primary experiments. Do not start cloud GPUs, train large models, upload, submit, or claim leaderboard improvement. Existing plan remains the immutable design reference. Actual L4, labeled-data, sealed and GPU gates stay pending until measured. Optional large architectures remain deferred.

Deliverable: `DACON_Redesign_H100_Experiments.ipynb`, reproducible builder, embedded runtime source, CPU integration evidence. Reuse original `graph_scoring.py` and `TemporalMusic` unchanged. No source or weight downloads without fixed provenance. Asset locations are user configuration, not hard-coded VESSL paths.

## Shared data API

Rows are JSON-compatible mappings following existing repository convention. CSV manifest columns: ID, path, audio_sha256, source, license, license_url, source_url, parent_ids (JSON array), artist_id, speaker_id, generator, kind, domain, FILE_FAKE, VOICE_FAKE, MUSIC_FAKE, VOICE_PRESENT, MUSIC_PRESENT. Labels are 0/1 or empty (unknown). `kind`: speech/instrumental/singing/mixed/neither. `domain`: natural/telephone/etc. Data preparer adds `group_id`, `split` (train/validation/sealed), `pair_id`, `view` (pure/mixed/observed), `event_intervals` (JSON array of component/start/end/label). Pair_id identifies an accompaniment slot, NOT a new independent group. Generated mixed row and its matched pure row have same pair_id, same group/split. Split originals before combining parents, never mix across splits. Provider/generator stratify or stress, not union grouping. Unknown sources are quarantined; historical input is explicitly diagnostic-only.

`redesign_data.prepare_data(manifest: Path, output: Path, *, seed=41, diagnostic=False, make_mixtures=True) -> dict` writes train.csv, validation.csv, sealed.csv, protocol.json, audit.json. Source checksum and license/provenance validation happens here on CPU. `redesign_data.read_rows(path: Path) -> list[dict]` is the common CSV loader, preserves unknowns. Own module may add helper modules prefixed redesign_data_/redesign_mix_. Training modules never load sealed automatically.

## Feature API

`redesign_features.extract_features(rows, assets: Path, cache: Path, *, device='cuda', deadline=None, views=('stem','raw')) -> dict` uses assets/baseline/script.py + assets/baseline/model/{panns,htdemucs,df_arena_1b}, assets/mert HF snapshot. Validate asset hashes from assets/asset_hashes.json (relative path -> sha256). No historical trained head used. Optional baseline ZIP preparation can materialize these assets safely.

`redesign_features.load_records(rows, cache: Path) -> dict` maps ID to numpy arrays. NPZ keys: stem [T,1024], raw [T,1024], aux [T,6] (raw/stem/vocal log-RMS, raw/stem audible, valid duration ratio), starts [T] in 16kHz samples, valid [T] boolean valid-time, stem_audible [T] boolean, voice_embedding [T,1280], voice_logits [T] (fake-minus-real), voice_probability [T], presence [T,2] (voice,music), evidence [3] (baseline bag voice fake, voice present, music present). Store per-file identity with audio/model/source/config hashes; stale cache fails closed. Local checksum lookup must agree with current rows and extractor/model identity. All data stays per-file independent. Original waveform native channels to separator; full-window/tail coverage; no quiet CPU fallback. Voice embedding via frozen classifier input hook with native prediction parity, avoid globally enabling trainability. PANNs same windows/support.

## Training API

`redesign_train.run_experiments(data: Path, cache: Path, output: Path, *, seeds=(41,42,43), epochs=300, patience=20, batch_size=64, device='cuda', deadline=None, arms=('A','B','C','D'), folds=5) -> dict`. Small modules own music residual and voice residual. A/C existing compact TemporalMusic stem; B/D shared hidden encoder + gated 198->32->64 zero-init residual, raw=stem capacity control. Use same pair/exposure lists and same seeded initialization, grouped train-internal early stop, conditional known labels, event masks. Global validation only for candidate choice after fitting. Seed-specific predictions and probability ensemble separate.

Results: output/summary.json, output/predictions/<candidate>.json with `labels`, `predictions` (official 6 cols), `groups`, `strata`, `window_scores`, `upstream_identity`; output/oof/<candidate>.json same plus per-row `held_out_group`, `trained_groups`, fold/checkpoint hashes. OOF fit must refit upstream on other train groups only; no global validation/sealed or historical heads. Same group internal early stop. Small CPU fixture may reduce epochs/folds/seeds without implying performance validation. Voice residual is eligible only on known labels; allow explicit provisional skip when singing/telephone gates fail. No fake synthetic embeddings in delivered real training path.

## File and evaluation API

`redesign_file.fit_relation(oof_path: Path, output: Path) -> dict`, `redesign_file.apply_relation(prediction_path: Path, relation_path: Path, output: Path) -> dict`. Fixed 12-feature order from plan, train-OOF standardizer, zero-init offset logistic, exact endpoints. Must validate full fitting provenance incl group disjointness. `window_scores` per ID carries voice_fake, music_fake, voice_present, music_present aligned 1d lists.

`redesign_evaluate.compare(control_path: Path, candidate_path: Path, output: Path, *, bootstrap=2000, seed=41) -> dict`: scorer reuse, exact full or identifiable weighted delta only when every changed output has complete relevant labels; paired group bootstrap, subgroup/regression/count gates, distinguish provisional/accepted. `redesign_evaluate.lock_candidate(prediction_path, report_path, output, *, sealed_panel_identity)` and `open_sealed(lock_path, prediction_path, output, *, panel_identity, access_registry)` bind hashes and one-time panel use. The data audit provides a canonical `sealed_panel_identity` independent of paths, labels, protocol settings, and nonsealed rows; the access registry is persistent under DATA, outside mutable OUTPUT. Every ensemble music and voice checkpoint participates in the exact locked model identity. Candidate promotion compares the final configured candidate against the fixed A-ensemble max control; within-candidate File correction remains a separate diagnostic, alongside A/B/C/D paired architecture comparisons. Sealed predictions must come from locked training weights; do not claim final acceptance without L4 or data gates.

## Notebook and resource API

Notebook builder bundles local source dependency closure, not weights/audio/secrets. CPU preparation and hash/readiness gate before feature extraction. Explicit configuration paths and flags for each expensive stage, GPU cap 4h with 15m export reserve, cancel/timeout report with partial OUTPUT export before re-raising, resumable verified artifacts, progress.json, result archive and readback checksums. No shell placeholders or absent CLI calls. Run All default safely performs setup/preflight and clearly reports stages not run; CPU integration mode exercises real heads/OOF/metrics/export on a labeled fixture with explicit non-performance disclaimer. Training execution flags only set by notebook user. No automatic cloud shutdown command or token in notebook; exported result plus instruction to stop workspace, optionally configured external command only after successful export.
