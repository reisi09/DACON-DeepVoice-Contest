### held-out 내부 cross-fitted GBM도 상한이 아닙니다

`0.07531→0.06640`, ADS `+0.004455`는 해당 데이터와 특징, depth-3 모델에서 얻은 결과입니다. 더 좋은 모델이 못 넘는 상한도 아니고, val에서 학습한 모델의 배포 성능 추정치도 아닙니다.

추가로 **pooled OOF EER**를 확인해야 합니다. 다섯 GBM이 내놓은 점수의 척도가 다르면, 이 점수를 한데 모은 EER에는 fold 간 보정 차이가 들어갑니다. 다음을 함께 보고해야 합니다.

- fold별 동일 행에서의 baseline 대비 FILE EER 차이
- pooled OOF EER
- fold별 클래스·그룹 수와 설정 선택 과정

### “Attention은 window에만 있어야 한다”는 과도한 단정입니다

scalar member 점수에 입력별 가중치를 주는 gating도 유효한 결합기입니다. 다만 이미 max·LME로 버린 시간 정보를 복원할 수는 없습니다. **window attention이 더 풍부한 정보를 활용할 수 있다는 설명**이 정확합니다.

또한 gated attention-MIL 자체가 순서를 이해한다는 보장은 없습니다. 위치 정보 없는 pooling은 여전히 순서에 불변일 수 있습니다.

`200 TFLOP`을 CPU `10–20 min`에 처리한다는 추정은 지속적으로 약 `167–333 GFLOP/s`를 내야 한다는 뜻입니다. 불가능하다고 단정할 수는 없지만, 현재 CPU·배치·I/O의 실측 없이 일정의 확정값으로 쓰면 안 됩니다.

### 거대 source component는 기존 CV를 무효화하지만, 대안 전체를 막지는 않습니다

**VERIFIED 산술:** `26,016/31,270 ≈ 83.2%`가 한 component입니다. 이 덩어리를 한 fold로 빼면 학습에 남는 것은 `5,254`행입니다. 원래 계획대로 fold 평균을 내면 서로 크게 다른 학습량의 실험을 섞게 됩니다.
