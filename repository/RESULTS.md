# 5개 파이프라인 비교 결과

2026-09-13 Colab A100에서 225개 음원을 처리하고, 원본 그룹이 분리된 holdout 65개로 비교했다. **이번 비교에서는 G0 공식 베이스라인을 유지한다.** G2는 같은 EER을 기록했고, 나머지 후보는 개선되지 않았다.

| 파이프라인 | 파일 EER · 65개 | 음성 EER · 정답 확인 가능 48개 | 음악 EER · 성분 존재 29개 |
|---|---:|---:|---:|
| G0 공식 베이스라인 | **12.35%** | **4.20%** | **30.79%** |
| G1 상위 2개 구간 평균 | 12.35% | 8.39% | 30.79% |
| G2 시간 정렬·성분 합집합 | **12.35%** | **4.20%** | **30.79%** |
| G3 원본·분리 신호 결합 | 15.65% | 4.20% | 38.42% |
| G4 학습형 결합 | 15.65% | 4.20% | 30.79% |

EER은 낮을수록 좋다. 모든 그래프에서 음악 존재 AUC는 1.0이었다. 음성이 없다는 확정 정답이 없으므로 **음성 존재 AUC와 대회 총점은 계산할 수 없다.** 이 표는 외부 검증셋 결과이며 리더보드 점수가 아니다.

G4는 파일·음성·음악 헤드를 각각 dev 160개·128개·68개로 학습했다. 각 헤드는 정답이 확인된 대상만 사용했고, 성분 헤드에는 실제 성분이 있는 자료만 넣었다. holdout으로 학습하거나 하이퍼파라미터를 다시 조정하지 않았다.

## 실행과 검증

- GPU: NVIDIA A100-SXM4-40GB. 노트북 전체 실행 614.35초, 약 **10분 14초**. 비교 코드 실행은 251.06초였다. 준비·패키징을 포함해 2시간 한도 이내에 끝났다.
- 종료 후 Colab 화면에서 **활성 세션 0개**, 사용률 0/시간, 남은 컴퓨팅 단위 **55.96개**를 확인했다. 시작 전 표시는 56.68개였다. 이 차이는 화면 관측값이며 최종 청구량을 별도로 조회한 것은 아니다.
- 공식 함수와 G0 공통 추론의 실제 혼합 음원 예측 차이: 최대 `4.0435765846780214e-11`.
- 60초 반복 음원: 4.247초, GPU 최대 할당 13.992 GiB, 최대 예약 19.318 GiB. 이 음원은 시간·메모리 확인용이며 성능 평가에는 넣지 않았다.
- 모델 특징은 한 번 계산해 5개 그래프에 재사용했다. G0 패키지는 필요 없는 원본 DF 분기를 생략한다. 평가 파일 간 예측값이나 통계는 사용하지 않는다.
- 선택한 G0 ZIP을 새 폴더에 풀고 실제 `script.py`를 실행했다. 더미 입력의 ID 순서·출력 확률을 검증했으며 노트북 예측과의 차이는 **0.0**이었다.
- 저장된 Colab 노트북의 코드 셀 10개가 모두 실행됐고 오류 출력은 없었다. 로컬 Python 3.11에서 저장된 특징과 결합 모델로 모든 holdout 지표를 재계산했으며 Colab 결과와 일치했다.
- 공식 EER의 동점 처리, 실제 성분 정답 마스크, 파일 간 독립성, 원본 그룹 누수, 손상된 확률, JSON 결합 모델의 수치 일치를 별도로 검증했다.

## 결과를 해석할 범위

holdout의 65개 음원은 21개 원본 그룹에서 나왔다. 전화채널 변형과 혼합본은 서로 연관돼 있으므로 독립 표본 65개로 해석할 수 없다. 음악 데이터는 실제 FMA와 합성 AIME라는 출처 차이가 있고, 사용한 생성기 설정은 dev와 holdout 양쪽에 나타난다. 또한 DF-Arena의 기존 학습 목록에 MLAAD가 포함돼 있어, 이번 음성 지표를 사전학습부터 완전히 독립된 평가로 볼 수 없다.

G1은 음성 EER을 악화시켰고, G3은 파일·음악 EER을 악화시켰다. G4도 holdout 개선을 보이지 않았다. 이 결과만으로 새로운 결합 규칙이 더 낫다고 판단할 근거는 없다. 다음 비교에서는 음성 없음 정답과 음악 출처·생성기 다양성을 먼저 보강해야 한다.

Colab은 Python 3.13.15 / torch 2.11.0+cu128이었고, 대회 서버는 Python 3.11.15 / torch 2.7.1+cu128 / L4다. A100 테스트만으로 L4에서의 60분 제한 준수를 확인한 것은 아니다.
