# 추가 수집분을 합친 새 데이터 분할

총 개수 제한을 없애고 train/val/test 70/15/15로 실제 CSV를 만들었다. HAIM 추가 수집 오디오 2,000개와 사이드카 2,000개가 모두 다운로드·원본 검증을 마친 뒤 만든 스냅샷이다. **다른 후보의 수집·학습 편입 검사가 남은 잠정본**이며, GPU 학습은 시작하지 않았다. `training_ready=false`다.

기존 16,042개와 신규 HAIM 2,000개를 합쳐 전체 18,042개를 목록에 기록했다. 검사를 통과한 후보 16,879개 중 real/fake 1:1로 가능한 최대 규모인 13,186개를 선별했다. 과반 클래스에서 남은 3,693개는 예비 목록으로 보존했다. 원본은 삭제하거나 복제하지 않았다.

신규 포함량은 **SonicMaster로 마스터링한 실제 음악 465개 + Lyria 생성 음악 320개 = 785개**다. 검사를 통과한 Lyria 500개 중 180개는 클래스 균형 때문에 예비 목록에 남는다. B1 500개 중 35개는 MTG 부모 식별 정보 또는 개별 이용조건 연결이 확인되지 않아 보류했다. C1 500개와 C2 500개도 목록에는 모두 반영했지만 같은 편집을 거친 real 대조군이 없어 학습 후보에서 보류했다. 기존 혼합 가공 128개는 부모 검토 대상으로 보존했다.

전체 real/fake 균형과 음성·음악 각각의 균형은 다르다. 희소한 가짜 음성 2,000개는 모두 보존했다. 연결된 화자 그룹은 네 개이며 train 두 개, val 한 개, test 한 개로 분리했다. 이 때문에 음성 fake만의 비율은 정확히 70/15/15가 아니다. 전체 분할은 반올림 오차 범위에서 요청 비율을 만족한다. 유형별로 같은 비율을 강제하려고 화자 그룹을 쪼개지는 않았다.

## 실제 검사와 남은 문제

선택한 13,186개 오디오의 원본 SHA-256을 모두 다시 확인했다. 신규 HAIM 2,000개는 전체 디코딩과 유한 값·무음 검사, 사이드카 해시·부모 연결 검사를 거쳤다. 이는 모든 음질·성분 정답을 청취 검증했다는 뜻은 아니다.

알려진 곡·아티스트·원본 발화·파생물·해시의 연결 그룹은 분할을 가로지르지 않는다. 진단용으로 보류한 파생물도 부모 연결에 포함했다. 실제 CSV에 부모 누수를 주입하면 검사기가 거부하며, 미상 정답의 mask를 1로 바꾼 경우도 거부한다. 기존 Balanced7144 원본 CSV의 해시도 그대로다.

부분 편집 C1/C2 1,000개 중 **541개**는 기록된 구간 끝이 디코딩한 길이를 0.15초 넘게 벗어난다. 구간 정답을 임의로 잘라 학습시키지 않았다. 부모 조건이 확인되지 않은 경우도 별도로 기록했다. 샴 대조군과 시간축 정합 검사를 끝내야 편입할 수 있다.

새 음성·가창 원본은 아직 이 분할에 들어가지 않았다. PartialSpoof train 25,380개와 dev 24,844개는 원본 archive 확보·색인을 마쳤지만, 전체 품질·부모 연결·부분 조작 라벨 검사는 남았다. ASVspoof5·CtrSVDD·VocalSet 및 나머지 전송도 수집 후 검사를 이어가야 한다. 이 스냅샷의 pending 파일 목록과 현재 다운로드 완료량은 다를 수 있다.

음악 보컬의 존재·진위가 미상인 행은 그대로 마스킹했다. 보컬 오탐을 해결할 성분별 정답이 모두 확보됐다고 볼 수 없다. 가짜 음성도 여전히 ASV2019에 집중돼 있다. 일부 Echoes 생성기는 val/test에 1~몇 개만 있어 개별 성능을 안정적으로 추정하기 어렵다.

음악에서 출처만 사용한 AUC는 val 0.9671, test 0.9613다. 길이만 사용한 AUC도 각각 0.8665, 0.9104다. 이는 학습 모델의 점수가 아니라 **남아 있는 출처·길이 편향**을 보여 주는 진단이다. 데이터 추가만으로 문제가 해결됐다고 주장하지 않는다.

과거 개발 노출이 기록된 행은 train 7,076개, val 1,610개, test 1,744개다. 그룹을 통한 노출도 포함한다. **현재 test는 독립 평가셋이 아니다.** 모델 성능을 보고 분할한 것은 아니지만 이번 검사에서 test의 라벨·분포를 확인했다.

1차 분할에서는 전체 클래스 균형만 맞추다가 test의 가짜 음성이 60개로 줄었다. 이후 희소한 음성 fake와 음악 real을 먼저 보존하는 조건을 추가했다. 이전 스냅샷은 `../reconstructed_bank_20260919_initial/`와 `../reconstructed_bank_20260919/`에 남겼다. 마지막 스냅샷은 새 HAIM 2,000개 전체의 부모 연결을 반영한 이 폴더다.

## 파일

- `selected.csv`, `train.csv`, `val.csv`, `test.csv`: 실제 선별·분할 목록.
- `combined_catalog.csv`: 기존·신규 전체 목록, 선택 여부, 보류 사유, 부모 그룹, 정답과 mask.
- `composition.csv`, `audit.json`: 출처·생성기·라벨 수량, 희소 유형, 누수 거부 검사, 편향 진단.
- `verification.json`, `provenance.json`: 선별 조건, SHA-256, 과거 노출, 재현용 코드·입력 해시.
- `pending_collection.csv`: 스냅샷 시점에 원본 검증을 끝내지 않은 전송 목록.

```sh
.venv/bin/python reconstruct_candidate_bank.py --output results/reconstructed_bank_NEXT
.venv/bin/python verify_reconstructed_bank.py --output results/reconstructed_bank_NEXT
```

스냅샷을 덮어쓰지 않는다. 현재 재구성 스크립트는 검증된 HAIM 추가분을 편입한다. 다른 후보는 원본별 프로토콜·부모 연결과 품질 검사를 구현한 뒤 편입해야 한다.

기존 H100 노트북과 학습 진입점은 이 잠정 분할로 바꾸지 않았다. 현재 로더는 train/val과 H100을 전제로 한다. test 격리, mask와 실제 손실 연결, 전처리 일치, 같은 workspace의 A100 전환과 약 16시간 내 처리량·VRAM 실측을 확인한 뒤 학습에 연결한다. 모델 구조는 HTDemucs base, frozen MERT330M layer12 WindowMIL, DF-Arena fc5, PANNs를 유지한다.

MTG 원본·아티스트 연결 근거는 [공식 저장소](https://github.com/MTG/mtg-jamendo-dataset)다. 고정 revision과 원본 해시는 `../candidate_acquisition_20260919/metadata/mtg_sources.json`에 있다. 사용자 요청에 따라 [Computer Use 스킬](/Users/choiwuseck/.codex/plugins/cache/openai-bundled/computer-use/1.0.1001103/skills/computer-use/SKILL.md)로 Claude Opus 5에 보조 검토를 맡겼으며, 기록은 `../candidate_acquisition_20260919/claude_reconstruction_review.txt`에 보관했다. 그 제안과 실제 검사 결과는 구별했다.
