## 무엇을 고쳤는가

- 기존 잠정본의 fake 일반 발화 595개를 **1,762개**로 늘렸습니다. 검증된 2,000개 중 238개는 화자 그룹을 유지하면서 val/test 구성을 맞추기 위해 예비 목록에 보존했습니다.
- fake 가창은 8,675개에서 **1,017개**로 줄였습니다. train의 일반 발화 fake와 같은 수입니다. 현재 real 가창도 1,017개입니다.
- 가창의 가수·원본 그룹은 유지했습니다. 가수 간 곡·악보 관계를 확인하지 못한 위험을 평가에 넣지 않도록 **가창은 train 전용**으로 정했습니다. 가창의 일반화 성능은 이번 val/test에서 측정하지 못합니다.
- CtrSVDD A03 **89개**, A04 **24개**를 train에 배치했습니다. A01 300개, A02 304개, A05 300개도 train에 있습니다. 모든 편입 대상 출처·생성기·라벨 조합이 train에 있으며, 원본이 20개 이상인 조합은 최소 20개, 그보다 작은 조합은 전부 포함했습니다. 이 최소치는 성능을 보증하는 기준이 아닙니다.
- 발화 평가의 real/fake를 같은 ASV 출처에서 맞췄습니다. LibriSpeech가 real이라는 출처 정보만으로 val/test 정답을 구별하는 문제를 막았습니다. LibriSpeech는 train에서만 사용합니다.
- val/test의 발화·음악 수를 거의 같게 맞췄습니다. train에는 가창이 있으므로 세 분할의 유형 비율이 모두 같지는 않습니다.

## 선별 기준과 남은 데이터

검증된 후보 43,603행에서 이번 기준을 만족하는 9,504행을 선택했습니다. 나머지 **34,099행은 예비 목록**에 있습니다. 전체 목록에는 편입 보류·중복 제외까지 합쳐 59,770행이 기록돼 있습니다. `combined_catalog.csv`의 `admission`, `selected`, `reason`, `assigned_group_split`에서 상태를 확인할 수 있습니다. 원본을 삭제하거나 음원을 변환하지 않았습니다.

정수 최적화는 먼저 위 조건을 만족하는 총량을 최대화하고, 같은 총량에서 일반 발화 fake를 최대한 보존한 뒤, 과거 노출 평가 행과 출처 구성의 편차를 줄이는 순서로 실행했습니다. 세 단계 모두 solver gap 0으로 종료했습니다. **9,504개는 이 명시된 조건 아래의 최대치**이며, 다른 정책에서도 항상 최대라는 뜻은 아닙니다. 모델 예측·점수로 선별하지 않았습니다.

## 검증한 항목

선택된 9,504개 원본의 SHA-256을 모두 대조했습니다. 원본 크기의 합은 14,939,622,208바이트입니다. 디스크의 전체 수집 용량은 이 수치와 다릅니다.

실제 train/val/test CSV의 구성, 고정 파일 해시, real/fake 비율, 유형별 균형, train 생성기 누락 여부, 알려진 부모·화자 그룹 중복을 확인했습니다. 부모 관계를 분할 밖으로 연결하거나 unknown 라벨의 마스크를 켜는 오류를 넣으면 검사기가 거부합니다. 기존 가창 편중, val/test 유형 불균형, 발화 출처와 정답이 일치했던 중간 구성도 거부하는지 검사했습니다. 동일 입력으로 CPU 선별을 반복해 ID와 split이 동일한지도 확인했습니다.

## 여전히 해석에 주의할 부분

- **독립 test가 아닙니다.** val 1,426행 중 997행, test 1,426행 중 1,001행은 과거 개발 노출 그룹입니다. 기존 발화 fake 전체가 과거 노출 자료여서 추가 수집 없이 이 한계를 없앨 수 없습니다. `*_historical.csv`와 `*_no_recorded_exposure.csv`를 따로 저장했습니다. 후자는 사전학습 노출까지 배제했다는 뜻이 아니며, 전체 평가셋을 대체할 균형 잡힌 독립 test도 아닙니다.
- 가창은 train에만 있어 별도 평가가 없습니다. A03/A04도 학습에 포함됐지만 평가 성능은 측정할 수 없습니다. 일부 작은 출처·생성기는 val/test에 없으며, `audit.json`에 0행 조합을 숨김없이 기록했습니다.
- 음악의 출처·길이 편향은 남았습니다. 이번 구성의 메타데이터 진단값은 모델 성능이 아닙니다. 출처만 쓴 AUC는 발화 val/test 0.5/0.5, 음악 약 0.9665/0.9686입니다. 최종 분할 이후 이 값으로 분할을 다시 조정하지 않았습니다.
- PartialSpoof 원본은 확보돼 있지만 부모 관계와 안전한 구간 라벨 편입이 미해결이므로 포함하지 않았습니다. CtrSVDD SVC와 HAIM C1/C2 등 기존 보류 자료도 계속 보류합니다.
- 알려진 그룹 중복 검사를 통과한 것이 모든 데이터셋 사이의 미발견 유사 곡·사전학습 노출까지 없다는 증거는 아닙니다.
- 학습 로더·노트북은 아직 이 결과로 전환하지 않았습니다. GPU는 기존 `wsp-9683432r72m7`의 H100 정지 상태이며 A100 전환·16시간 처리량·VRAM 검증을 하지 않았습니다. 자동 수집 작업도 일시정지했습니다.

## 파일과 재현 방법

- 학습: `train.csv`
- 모델 선택용 검증: `val.csv`
- 추가 튜닝에 사용하지 않을 평가: `test.csv` — 위 과거 노출 한계 적용
- 전체 선택 목록: `selected.csv`
- 구성 및 보류 사유: `composition.csv`, `combined_catalog.csv`, `audit.json`
- 검사 및 해시: `policy_checks.json`, `verification.json`, `provenance.json`, `reproducibility.json`

```sh
.venv/bin/python rebuild_existing_bank.py --output results/NEW_EXISTING_ONLY_SNAPSHOT
.venv/bin/python verify_existing_bank.py --output results/NEW_EXISTING_ONLY_SNAPSHOT
.venv/bin/python verify_reconstructed_bank.py --output results/NEW_EXISTING_ONLY_SNAPSHOT
```

`rebuild_existing_bank.py`는 이전에 검증한 `reconstructed_bank_20260919_ctrsvdd_dev/combined_catalog.csv`의 고정 해시를 확인한 뒤 사용하며, 다운로드 함수나 GPU 실행을 호출하지 않습니다. 이미 존재하는 출력 디렉터리에는 덮어쓰지 않습니다.
