# H100 후속 실험 실행 범위

노트북: `DACON_Voice_Music_H100.ipynb`. 기존 workspace `wsp-9683432r72m7`만 재사용한다. 새 실행 경로는 `/root/voice_music_h100_20260917`, 공유 경로는 `objvol-a5gxdg7er70i/voice-music-h100-20260917/`이다. 이전 여섯 실험의 종료 시각은 변경하지 않는다. 새 실행은 시작부터 최대 3,600초, 계산 종료 후 600초를 결과 보존에 남긴다.

1. 4초·같은 음성 gain으로 만든 64개 혼합 대조군을 포함해 568개 입력을 추론한다. HTDemucs 파일당 1회, DF raw/vocals 비교.
2. AntiDeepfake XLS-R-1B를 비교한다. 원본 Fairseq와 실제 오디오 3개의 최대 로짓 차이 0.000020503997802734375. H100에서도 일치를 확인한다. M330/PANNs/File max 고정.
3. 과거 480개 음성의 6명 화자 그룹을 복원해 speech-only VoiceResidual 진단을 학습한다. 가창 검증이 없어 배포 승격 금지.
4. NSynth를 두 군에서 모두 제거하고 기존 데이터 대조군과 새 음악 train 52개 추가군을 seed 41·17 epochs로 비교한다.
5. 별도 calibration 그룹에서 Platt 계수를 정하고 dev에서 max/noisy-OR를 비교한다. 테스트 통계는 사용하지 않는다.
6. dev 기본·4초·전화·MP3 조건 모두에서 File/Music EER가 악화되지 않고 기본 가중 지표가 좋아져야 seed 42·43을 각각 17 epochs 추가한다. 동률이면 대조군 유지. 선택 저장 후 test 확인.

새 음악은 FMA 64곡, SONICS 38곡으로 이전 음악 ID·아티스트를 제외했다. 음성 32개는 이전에 공개한 진단 패널이므로 새로운 독립 검증으로 주장하지 않는다. 전체 독립 그룹 106개이며 독립 원천 300개 기준에 못 미친다. 음성 청취 검수와 가창 검증이 끝나지 않았고 FMA/SONICS 출처 편향도 남아 있다. 모든 결과는 원인 진단용이며 공식 점수·리더보드 개선을 주장하지 않는다.

입력/모델을 GPU 정지 상태에서 업로드하고 전체 다운로드 해시를 확인한다. 로컬 watchdog은 300초마다 확인하고 결과 ZIP과 EXPORT_SHA256.json 모든 항목을 검증한 뒤 compute를 정지한다. 그 후 원래 bootstrap을 복원한다. 오류 시 부분 결과와 근거를 확보하고 종료한다.
