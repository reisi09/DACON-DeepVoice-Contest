# MERT12 전체 데이터 재학습·제출 기록

## 현재 상태

전체 데이터 재학습, 수정 ZIP의 A100 추론 검증, 결과 다운로드·검증과 GPU 정지를 완료했다. **2026-09-18 10:30:25 KST에 공식 제출 92294로 접수됐으며, 현재 채점 중이다.** 공식 점수와 L4 전체 실행 결과는 아직 확인되지 않았다.

이전 실행의 부분 결과를 검증해 내려받고 GPU를 정지한 상태에서 수정 파일을 준비했다. 6GB 전체 ZIP 업로드가 실패해 기존 원격 ZIP과 수정 멤버 2개를 이용한 재구성으로 전환했다. 로컬과 원격 재구성본 모두 최종 ZIP의 전체 바이트·해시와 같음을 확인했다. A100 재개 후에는 ZIP 재구성과 검증만 수행했으며 다시 학습하지 않았다.

원래 종료 시각 **2026-09-18 10:34:37 KST**를 변경하지 않았으며, **10:28:51 KST**에 A100의 `state=stopped`, `phase=standby`를 확인했다. 이후 별도 CLI 조회에서도 같은 상태를 확인했다.

## 학습 범위와 배치 실측

학습 대상은 기존 외부 데이터의 원본 음악 1,322개(REAL 218 / FAKE 1,104)다. 이전 train/calibration/dev/test를 모두 합쳤다. 7,101개 파생 입력 전체를 학습한 것은 아니다. MERT-330은 고정하고 12층 특징으로 131,329개 파라미터의 MLP만 학습했다. 음성·존재 모델과 File-max 결합은 유지했다.

seed 41·42·43마다 batch 32로 500회 업데이트했다. 모든 1,322개가 각 seed에서 실제 학습에 최소 한 번 사용됐고, 모든 학습 파라미터의 양의 gradient와 가중치 변화를 확인했다. 기존 sampling은 109개를 한 번도 사용하지 않아, 클래스별 균형을 유지하면서 전체 노출을 보장하는 prefix로 수정했다.

동일한 8,192개 샘플을 처리한 A100 실측이다. 본 학습과 분리한 임시 head에서 5회 warm-up 후 한 번 측정했다.

| 배치 | 소요 시간 | 처리량(샘플/초) | PyTorch 최대 할당 메모리 |
|---|---:|---:|---:|
| 32 | 0.33764초 | 24,263 | 72.7 MiB |
| 128 | 0.08542초 | 95,906 | 72.8 MiB |
| 256 | 0.04195초 | 195,283 | 73.4 MiB |

배치 256의 샘플 처리량은 약 8배였지만, 같은 샘플 수에서 optimizer 업데이트 횟수도 1/8이 된다. 이 결과는 수렴이나 점수 개선의 근거가 아니다. head 학습 자체가 짧아 제출 후보는 기존 batch 32·500회 설정을 유지했다. 이 메모리는 PyTorch 할당량이며 GPU 프로세스 전체 메모리를 뜻하지 않는다.

## 초기 실제 추론 검증과 원인 진단

기존 ZIP을 풀어 원본 4개, 역순 4개, 부분집합 2개를 별도 CUDA 프로세스로 실행했다. 같은 ID의 5개 확률을 비교한 최대 차이는 두 비교 모두 **0**이었다. 원본 4개 실행은 47.43초, PyTorch 최대 할당량은 6,582,434,304 bytes였다. 이는 A100의 소규모 실행 결과이며 공식 L4 전체 실행시간 검증이 아니다.

H100 특징 캐시에서 계산한 음악 확률과 A100 원본 오디오 추론값의 최대 절대 차이는 **0.00019127128483675815**로, 사전에 정한 **0.00001**을 초과했다. 이 초기 검증은 실패했으며, 당시 뒤에 배치한 무음·60초 스테레오·MP3 검증은 실행하지 않았다. 수정 후의 최종 결과는 다음 절에 별도로 기록했다.

초기 조사에서 확인한 환경 차이는 다음과 같다. 아래에 후속 진단 결과를 함께 기록했다.

| 항목 | H100 특징 추출 | A100 초기 추론 검증 |
|---|---|---|
| Python | 3.11.13 | 3.13.9 |
| PyTorch | 2.7.1+cu128 | 2.9.1+cu130 |
| FFmpeg 실행 파일 확인 | imageio static 7.0.2 존재 확인; 실제 Demucs 호출 경로는 기록하지 않음 | system 6.1.1 사용 |
| MERT 창 배치 | 최대 8 | 1 |

추가 A100 진단에서 같은 반주와 같은 입력 텐서를 배치 3으로 처리하거나 한 창씩 처리했을 때 특징값 최대 차이는 약 `3.05e-5`, 음악 확률 차이는 최대 `1.57e-9`였다. Python 3.11·PyTorch 2.7.1 환경에서도 초기 A100 결과가 재현됐다. CPU에서 Transformers 4.51.3과 4.57.6을 비교한 동일 입력의 MERT 특징은 완전히 같았다. 이 비교들은 큰 캐시 차이의 원인이 배치나 해당 라이브러리 버전 변경이라는 가설을 지지하지 않았다.

실제 원인은 **Demucs 입력의 리샘플링 경로**였다. Demucs의 기본 `load_track`은 FFmpeg 실행에 실패하면 조용히 `torchaudio.load + demucs.audio.convert_audio`로 전환한다. FFmpeg 유무에 따라 SWR와 julius 리샘플링 경로가 달라지는 것이다. 같은 원본에 torchaudio 경로를 명시적으로 적용하자 H100 특징이 재현됐으며, CPU에서 원본 4개 전체의 음악 확률 최대 차이는 **1.346343196928501e-7**로 기존 `1e-5` 기준을 통과했다.

수정 코드는 이 torchaudio 경로를 고정한다. 학습 가중치, 배치, 업데이트 횟수, 허용치는 변경하지 않았다. 음성·음악 스템을 함께 만드는 입력 전처리를 고친 것이므로, 음성 모델의 가중치는 같아도 초기 FFmpeg 경로의 음성 예측과 완전히 같다고 주장하지 않는다.

수정 ZIP: [MERT12_full1322_submit.zip](../../submissions/MERT12_full1322_submit.zip) · 6,268,222,843 bytes · SHA-256 `e7bebbded6fef06517db0d42421a575a0440849248de99856796ffc3e5eb5ee5`.

## 최종 A100 검증과 공식 제출

attempt6은 Python 3.11·PyTorch 2.7.1+cu128에서 수정 ZIP을 풀어 실행했다. 기존 seed 41·42·43 체크포인트의 해시를 유지했고 다시 학습하지 않았다.

| 항목 | 확인 결과 |
|---|---|
| 원본 4개·역순 4개·부분집합 2개 | 같은 ID의 예측 최대 차이 0 |
| 캐시 대비 원본 음악 확률 | 최대 차이 3.971516315814938e-8; 고정 허용치 1e-5 통과 |
| 보충 입력 | 4초 모노 무음 WAV, 60초 실제 스테레오 FLAC, 6초 MP3 모두 CUDA 실행 통과 |
| 보충 출력 | 유한한 확률, 범위 [0, 0.9999964237]; 실행 39.27초 |
| 메모리 | 최종 원본 실행의 PyTorch 최대 할당 6,556,092,416 bytes |
| 파일 검증 | 제출 ZIP 45개 멤버 해시·CRC, evidence 23개 파일 해시 검증 |
| 실행 노트북 | 최종 QA 코드 셀 1개 실제 실행, 오류 출력 0개 |
| 자원 | 검증 후 A100 stopped/standby; 원래 종료 시각 준수 |

패키지 생성 시점의 receipt에 있는 `gpu_end_to_end_verified:false`는 생성 당시 상태다. 이후 성공은 해시가 같은 ZIP에 연결된 [최종 QA receipt](downloaded/evidence/output/final_qa_receipt.json)와 [실행 노트북](downloaded/evidence/output/DACON_MERT12_Final_QA_Executed.ipynb)으로 확인한다. 최초 학습 노트북은 뒤의 추론 단계에서 실패했으므로 전체 실행 성공으로 표현하지 않는다.

공식 제출은 **92294**, 파일명은 `MERT12_full1322_submit.zip`이다. 제출 완료 창과 신규 목록의 파일명·메모·ZIP 해시·접수 시각을 확인했고, 재제출하지 않았다. 현재 **채점 중**이며 기존 최고 제출 90735의 **0.7396465503**과 비교할 새 점수는 아직 없다. 5분 간격 자동 점검은 공식 상태가 달라질 때만 알리고, GPU는 다시 시작하지 않는다. 근거: [공식 제출 기록](official_submission.json), [나의 제출 페이지](https://dacon.io/competitions/official/236749/mysubmission).

## 해석의 한계

이 재학습에는 독립 검증 데이터가 남아 있지 않다. FMA/SONICS 출처 편향과 기존 음성 라벨·가창 검증의 한계도 해소되지 않았다. 패키지 무결성, gradient, 파일 독립성 검증은 공식 점수나 일반화 성능의 증거가 아니다. 허용된 외부 자료만 사용하고 공식 숨김 테스트 학습이나 파일 간 통계 보정은 수행하지 않았다.
