# Additional music sources inspected on 2026-09-18

The selected acquisition is **JamendoMaxCaps real music + HAIM ACE-Step/MusicGen + original-author Kaggle SunoCaps**. This increases recorded track and corpus diversity. Existing training already contains ACE-Step, MusicGen and Suno in Echoes, so this is not a first exposure to those generator families. Adding these corpora does not itself remove the source/label confound.

## Exact retrieval contracts

JamendoMaxCaps provides original JSONL metadata at repository root in date-named files, with `id`, `artist_id`, `artist_name`, `license_ccurl`, `duration`, `audiodownload` and `audiodownload_allowed`. The HF collection card is CC BY-SA 3.0, but individual track licenses differ; the collection label must not overwrite them. Twenty pinned JSONLs, from `2008-01-01.jsonl` through `2008-04-05.jsonl`, were fetched and parsed: **20,414 rows** before filtering/deduplication. The SHA-256 receipt is `_workspace/local_sampler_20260918/new_data/additional_training/metadata/research_metadata_receipt.json`. The full audio collection is over 1 TB, so use the original public track download URLs for selected metadata rows. Instrumental tags are not verified voice-absence labels. [Dataset metadata documentation](https://huggingface.co/datasets/amaai-lab/JamendoMaxCaps/blob/13090d785d071dcd617636deaa4a9775936ac995/README.md)

HAIM supplies individual raw files. ACE-Step metadata is `A_full_generation/A2_fake/acestep/metadata.csv`: `file_name`, `track_id`, prompt, lyrics, editing type, seed and duration. MusicGen metadata is `A_full_generation/A2_fake/musicgen/metadata.csv`: `file_name` and UUID-like `track_id`; paths distinguish `large`, `medium`, etc. The card declares CC BY-NC 4.0 for non-commercial academic research and distinguishes audio from link-only platform material. The raw dataset has 6,000 ACE-Step and 5,000 MusicGen tracks; the 100-row viewer parquet files are previews. HAIM's real subset is **not admitted** here: its inspected metadata supplied only local IDs and generic `Creative Commons`, without a verified original-artist/per-track-license join. The selected fake metadata also does not prove a source-reference pairing to Jamendo. [Pinned card](https://huggingface.co/datasets/mippia/HAIM/blob/371be01815b65274762d6d0a33e2cb70e24b9baa/README.md), [original project](https://github.com/Mippia/HAIM_dataset)

SunoCaps provides 256 generated files from 64 MusicCaps prompt sources. The inspected CSV contains `ytid_V`, prompt/aspect fields and human annotations; a source ID is the 11-character MusicCaps YouTube identifier plus a variant suffix `_1`–`_4`. The original human YouTube audio is not downloaded. Pinned public endpoint: `https://www.kaggle.com/api/v1/datasets/download/miguelcivit/sunocaps/<encoded-file>?datasetVersionNumber=7`. Responses are either a single-file ZIP (checked by name, size and CRC) or raw MP3; both are decoded before admission. **64 originals totaling 149,962,752 bytes are acquired** and assigned wholly to `confirmation_external`. Exact source-byte/decoded-PCM overlap with recorded history and the frozen 64-parent confirmation panel is zero. Prepared views are 63 eight-second cores and one naturally five-second core, without repetition or padding. Evidence: `sunocaps_receipt.json` and `sunocaps_verification.json`. [Original-author Kaggle card](https://www.kaggle.com/datasets/miguelcivit/sunocaps)

## HAIM conditioning review

The official project at GitHub commit `48e6a131cd74f134ed4a748f9c172dc456b707c1` passes only generic text prompts into [MusicGen](https://github.com/Mippia/HAIM_dataset/blob/48e6a131cd74f134ed4a748f9c172dc456b707c1/scripts/generation/generate_musicgen.py#L78-L93). The [large-model script](https://github.com/Mippia/HAIM_dataset/blob/48e6a131cd74f134ed4a748f9c172dc456b707c1/scripts/generation/gen_musicgen_large.py#L58-L62) does likewise. The [ACE-Step direct path](https://github.com/Mippia/HAIM_dataset/blob/48e6a131cd74f134ed4a748f9c172dc456b707c1/scripts/generation/gen_acestep_direct.py#L97-L106) uses captions with `task_type="text2music"`; [prompt construction](https://github.com/Mippia/HAIM_dataset/blob/48e6a131cd74f134ed4a748f9c172dc456b707c1/scripts/generation/utils.py#L435-L440) cycles fixed genre descriptions. These published A2 recipes do not feed Jamendo audio or captions into the models. This is stronger than a binary folder label, but it does not supply a complete per-file UUID-to-generation-run attestation. ACE metadata has 1,000 explicit `text_to_music` rows and 5,000 blank editing-type rows; missing entries are not silently inferred from the column alone. Code snapshots and hashes are recorded in `hf_training_sources_conditioning.json`.

All admission decisions require original bytes, full decoded-PCM hashes, known historical/confirmation identity exclusions and preserved unknown voice labels. Exact-hash exclusion cannot establish absence of every near-duplicate, and missing cross-corpus platform IDs are retained as a limitation. Public availability or a repository-level license alone is not sufficient evidence for a particular track's rights. DACON rule interpretation remains the root task's separately archived official-rule check; this research does not invent a publication-date cutoff or claim organizer approval of individual corpora.
