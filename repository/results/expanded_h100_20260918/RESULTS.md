# 확장 데이터 H100 실험 결과

4조건 × 3 seed의 학습과 평가를 모두 마쳤다. 이번 분할에서는 확장 학습 설정의 MERT 평균·MIL이 기존 831개 기준선보다 좋아졌다. AST 마지막 block 학습은 MERT 평균보다 나빴다. 이 결과만으로 ViT 계열 전체가 부적합하다고 판단할 수는 없다.

| 조건 | Dev 240개 | Calibration 160개 | Test 240개 | Mustango 평가 200개 |
|---|---:|---:|---:|---:|
| 기존 831개 · MERT 평균 | 17.56% | 16.33% | 14.14% | 30.00% |
| 확장 데이터 · MERT 평균 | 8.78% | 6.83% | 6.21% | 18.00% |
| 확장 데이터 · MERT MIL | 7.89% | 8.17% | 7.07% | 20.33% |
| 확장 데이터 · AST | 11.22% | 10.00% | 15.86% | 29.67% |

위 수치는 세 seed의 예측 확률을 평균한 Music EER다. 낮을수록 좋으며 seed별 EER의 평균과 다르다. DACON 제출 점수는 없다. 새 분할이므로 과거 실험의 다른 평가 집합과 직접 비교하지 않는다.

Dev만으로 정한 최종 후보는 MIL이다. Test에서는 평균 집계가 더 낮았지만, Test 결과를 보고 후보를 바꾸지는 않았다. 평균과 MIL의 Test EER 차이는 +0.86%p(MIL−평균), 그룹 bootstrap 95% 구간은 −2.60~+2.15%p로 우열이 확실하지 않다.

기존 기준선 대비 확장 평균의 Test 개선은 −7.93%p이며, 그룹 bootstrap 95% 구간은 −12.44~−3.66%p다. Mustango 평가에서는 −12.00%p(95% 구간 −20.48~−4.80%p)였다. 알려진 원본·아티스트·프롬프트 연결 성분을 묶어 1,000회 paired bootstrap(seed 41)을 수행했다. Test 연결 성분은 221개, Mustango 평가는 200개다. 이 구간은 해당 표본 안의 변동을 나타내며 새로운 데이터 출처 전체에 대한 보장은 아니다.

## 해석과 한계

- 학습은 기존 831개에서 3,659개로 확대됐다. 추가분에는 새 원본 2,700개와 기존 partial/sham 128개가 함께 들어갔으므로, 차이를 외부 데이터만의 단독 효과로 분리할 수 없다.
- 평균·MIL·AST 비교는 같은 확장 학습 집합을 사용했다. MIL/AST에는 구간 손실도 추가돼 구조와 학습 목적이 함께 바뀌었다.
- AST는 고정 prefix와 마지막 block·정규화·head 학습이다. 전체 ViT 미세조정 실험은 아니다. 현재 설정의 Test EER는 15.86%로 확장 MERT 평균의 6.21%보다 높았다.
- Mustango 및 해당 프롬프트의 다른 생성기 결과를 학습에서 제외했다. 다만 사전학습 중복이 없음을 입증한 평가는 아니다. MusicGen 미공개 프롬프트, 미확인 별칭과 유사 음원도 남은 한계다.
- 새 음악의 음성 라벨은 미확인 상태를 유지했다. ASV 128개는 기존 음성 분기의 진단용이다. 공식 전체 점수와 음성 분기의 독립 일반화 성능을 이 실험으로 확정할 수 없다.

다음 우선순위는 MERT 평균과 MIL을 새로운 그룹 분할에서 다시 비교하고, 공식 평가에 필요한 음성·존재 라벨의 공백을 줄이는 것이다. 현재 Test와 Mustango 결과를 반복적으로 보며 조정하면 독립 평가 의미가 약해진다. 추가 GPU 실험이나 DACON 제출은 이번 완료 작업에 포함하지 않았다.

## 실행과 검증

H100 80GB 1대를 사용했다. 유효 배치와 실제 학습 microbatch는 256이다. AST 처리량 측정의 최대 할당 메모리는 39,583,876,608 bytes, MERT 특징 추출은 21,718,520,320 bytes였다. 음원 4,627개, 구간 13,660개를 처리했다.

초기에는 접속 주소 형식, Jupyter 준비 시간, 기존 환경의 pip 부재 때문에 실행 준비를 수정했다. 이후 작업 중 정지 원인은 현재 증거로 확정하지 못했다. 원격에는 모든 특징과 평가용 음성 처리가 끝난 배열이 남아 있었고 최종 index만 없었다. 원본 해시·구현·패키지·모델 동일성, 구간 라벨·마스크, 모든 MERT/AST 수치 및 고정 분기 확률을 검사하고 해시를 기록한 뒤, 원래 학습 코드를 실행했다. 복구 기록은 `cache_recovery.json`과 `recovery_dispatch.json`에 있다. 중단 전 stage별 세부 시간은 복구할 수 없어 빈 값으로 남겼다.

12개 checkpoint의 잠금 해시, 로컬과 GPU의 여섯 샘플링 순서, 학습 원본 전부의 노출을 확인했다. 저장된 세 seed의 예측으로 ensemble을 다시 계산해 CSV와 일치함을 확인했고, 16개 집합별 EER를 재계산했다. 실행 노트북에 오류 출력은 없다.

최종 archive는 97,500,103 bytes이며 SHA-256은 `d30128914579dca44f5c849e0bc921e5271620d55f463b8f40bd0a40dc0aa67c`다. 122개 파일을 내려받아 검증한 뒤 H100을 정지했다. 기존 A100도 정지 상태이며 자동 시작 스크립트는 유휴 상태다.

원래 실행 노트북의 마지막 그래프에서 공유 축 때문에 오른쪽 막대가 잘린 것을 발견했다. 원본 archive는 보존하고, 검증된 결과로 그래프만 다시 그린 `DACON_Expanded_H100_Results.ipynb`를 별도로 만들었다. 학습·평가·후보 선정은 바뀌지 않았다.
