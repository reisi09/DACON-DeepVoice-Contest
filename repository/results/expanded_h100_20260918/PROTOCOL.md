# 신규 데이터 H100 실험

사용자 승인 범위: 수집한 데이터로 새 분할과 실행 가능한 노트북을 만들고, 자료를 먼저 업로드·검증한 뒤 **기존 H100 1대에서 최대 4시간** 실험한다. A100 계획은 이 설정으로 대체한다. 제출은 하지 않는다.

## 데이터와 분할

- 총 4,627개: 신규 원본 3,668개 + 기존 학습 원본 831개 + 기존 경계 일치 partial/sham 128개.
- 신규 음악 3,540개: train 2,700, dev 240, calibration 160, test 240, Mustango 평가 200(진짜 50·Mustango 150).
- ASV 음성 128개: 화자·변환 입력을 연결한 네 집합에서 진짜·가짜 각각 16개씩 고른 고정 음성 분기 진단 자료다. 음성 모델을 학습하거나 음악 모델을 선택하는 데 쓰지 않는다. DF-Arena의 사전학습 자료와 겹치므로 독립 평가라고 부르지 않는다.
- 기존 기준선 831개와 partial/sham 128개는 train에만 둔다. 이전 dev·test·confirmation 자료는 이번 실험에 넣지 않고 보존한다.
- 실제 아티스트, SONICS 원본 ID, FakeMusicCaps 공통 프롬프트를 기준으로 분리한다. FMA/Jamendo의 Mikroben Krieg 이름 일치 후보는 보수적으로 같은 test 집합에 둔다.
- ACE-Step은 정규화한 프롬프트로 묶고 그룹마다 원본 하나를 고른다. 기존 pilot과 같은 프롬프트는 이번 신규 패널에서 제외한다. MusicGen의 원 프롬프트는 없어 녹음 단위 독립성만 확인했다.
- Mustango용 150개 프롬프트와 본 실험용 132개 프롬프트는 서로 다르다. Mustango의 다른 생성기 형제 출력과 본 실험 프롬프트의 Mustango 출력은 제외한다.
- 생성기·출처·프롬프트 선정은 예측값 없이 고정했다. 알려지지 않은 아티스트 별칭, 재인코딩 유사 음원, Echoes↔MusicCaps 관계, 사전학습 노출은 여전히 한계다. 이 분할은 출처 전체를 보지 않은 평가가 아니다.

## 비교

같은 feature 추출과 dev 기준으로 네 조건을 비교하며 seed는 41·42·43이다.

1. 기존 원본 831개만 학습한 MERT 평균+MLP: 데이터 확장 효과의 기준선.
2. 확대 학습 자료의 MERT 평균+MLP.
3. 같은 확대 자료의 MERT 시간별 MIL 집계.
4. 같은 확대 자료의 AST: ViT 계열 스펙트로그램 모델. 앞부분을 고정하고 마지막 Transformer block·정규화·patch head를 학습한다.

MIL/AST에는 알려진 음악 구간의 local BCE 0.25가 추가된다. 따라서 시간 집계·AST 비교는 구조와 목적함수가 함께 달라진 실험이다. 전체 backbone 미세조정이라고 부르지 않는다.

유효 배치는 **256**, 업데이트는 **96회**, dev 평가는 24회마다 한다. source→generator→parent 균형 추출을 사용하고 모든 학습 parent의 노출을 GPU 시작 전에 검사한다. 실제 처리 배치는 32·64·128·256을 측정해 VRAM 80% 이내에서 최고 처리량의 90% 이상인 가장 큰 값을 택한다. 필요한 경우 gradient accumulation으로 유효 배치를 유지한다.

각 seed의 checkpoint는 dev Music EER, 동률이면 dev BCE로 선택한다. 세 seed 확률을 평균한 dev 결과로 최종 구조를 정한다. 모든 checkpoint를 잠근 뒤에만 test와 Mustango 평가를 계산한다. calibration 결과는 선택에 쓰지 않으며 이번 실행에서 별도 보정도 학습하지 않는다. train 전체 재예측은 생략한다.

## 전처리·자원·검증

새 음원은 중앙 최대 8초를 자연 길이 그대로 사용한다. 16kHz mono float WAV로 저장하고 기존 기준선과 같은 peak 0.6 상한을 적용한다. 음원 반복이나 시간 늘리기는 하지 않는다. 음악 데이터의 voice 라벨과 음성 데이터의 music authenticity 라벨은 미확인 상태를 유지한다. 음악 구간 라벨은 데이터 출처의 전체 음악 합성 여부를 crop에 적용한 것으로, 전수 청취 진실값은 아니다.

수집 원본은 그대로 보존한다. 파생 WAV는 128개 이하 묶음으로 업로드하고 전체 bytes·SHA를 재다운로드해 확인한 뒤 로컬 임시 묶음을 지운다. 로컬에 전체 음원 사본을 다시 쌓지 않는다. 모델은 이미 업로드된 원본 가중치와 AST 고정 revision을 재사용하고 실행 시 해시를 재검증한다.

H100 시작 전에 데이터, 모델 참조, 실행 소스, 노트북, 새 bootstrap을 올리고 검증한다. 예전 자동 시작 스크립트는 백업 후 비활성화하여 이전 실험의 재실행을 막는다. 처음에 대표 자료로 실제 처리 속도를 재고 4시간 내 전체 작업 가능성을 추정한다. 예산을 넘는 추정이면 점수로 표본을 줄이지 않고 중단·보고한다.

시작 시 확정한 절대 종료 시각은 재시작해도 늘리지 않는다. 마지막 10분은 결과 저장·다운로드에 남기며, 독립 감시 프로세스도 4시간 시점에 중지한다. 5분마다 상태를 확인하고 결과를 검증해 내려받으면 GPU를 멈춘다.

로컬 EER·AUC와 공식 DACON 점수는 구분한다. 현재 라벨만으로 전체 공식 점수가 정의되지 않는 집합은 `null`로 남긴다. 실행 전 수치와 예상 소요 시간은 성능 결과가 아니다.
