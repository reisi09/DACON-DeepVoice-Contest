이번에 재계산한 A/B 검증셋은 129개 파일이지만 서로 연결되지 않은 원본 그룹은 12개입니다. 실제 곡 7개, NSynth 실제 라벨 20개, Echoes 가짜 102개로 구성되어 있습니다. NSynth를 제외하면 109개 파일과 원본 그룹 7개가 남습니다. 자연 음성·가짜 음성의 균형 잡힌 검증셋도 없고, Music Presence의 음악 없음(0) 클래스도 없어 공식 총점을 계산할 수 없습니다.

전체 검증에서는 좋아 보이던 B + noisy OR가 실제 곡 포함 부분집합에서는 나빠집니다. 실제 곡이 7개뿐이라 한 곡의 순위 변화에도 EER가 크게 움직입니다. 이 표는 검증셋 민감도를 확인한 결과이며, A나 OOF 후보를 새 우승 모델로 선정할 근거는 아닙니다. 재계산 대상은 이전 A/B 검증 예측입니다. 1696개 전체 데이터로 다시 학습한 B_full1696의 독립 평가가 아닙니다.

기존 음성 증거는 `max_t(VOICE_PRESENT_t) * max_t(VOICE_FAKE_t)`입니다. 두 최대값이 서로 다른 시점에서 나올 수 있습니다. 진단 후보는 File 계산에서만 `max_t(VOICE_PRESENT_t * VOICE_FAKE_t)`로 바꾸고, 음악 bag 출력과 나머지 네 제출 확률은 그대로 두었습니다. 이것은 기존 구현과 학습·추론의 불일치를 고친 것이 아니라, 잠겨 있던 설계와 비교하는 새 가설입니다.

실제 곡 `Empower Thee`에서는 음성 증거가 0.316329 → 0.091538로 줄지만 음악 증거는 0.683626으로 높게 남습니다. `Wir Werden Gott`에서는 음성 증거가 0.749264 → 0.698860으로 조금만 줄고 음악 증거는 0.095231입니다. 첫 사례에는 시간 결합과 음악 분류기 오류가 함께 있고, 두 번째는 시간 결합만으로 설명하기 어렵습니다. 보컬 분리 결과와 음성 존재·진위 판정을 따로 살펴봐야 합니다. 이 후보는 모든 File 점수를 같거나 낮게 만들므로 실제 곡 오탐 감소만 보고 채택하면 가짜 음성을 놓치는 문제가 생길 수 있습니다.

| 순서 | 확인할 가설 | 고정할 것과 바꿀 것 | 다음 단계로 넘어갈 근거 |

순서 4의 head 실험이 안정적으로 개선된 뒤 seed 41/42/43을 확인합니다. encoder 미세조정이나 새 encoder 추가는 그 다음입니다. 처음부터 모델, 데이터 비율, loss, pooling, 전처리를 한 번에 바꾸지 않습니다. 후보 선택은 공식 가중치 `0.45 File + 0.18 Voice + 0.27 Music + 0.05 Voice Presence + 0.05 Music Presence`에 맞추되, EER의 개선 방향은 감소이고 AUC는 증가입니다. Voice 라벨이 빠진 Music EER만으로 공식 총점 향상을 주장하지 않습니다.

EER는 점수 순위로 ROC를 계산합니다. 단일 출력의 임계값을 0.5에서 다른 값으로 바꾸거나 엄격히 단조인 보정을 적용하는 것만으로는 그 출력의 EER가 좋아지지 않습니다. 구성 요소 보정이 File 결합의 순위를 바꾸는 효과는 따로 검증할 수 있습니다. Presence AUC가 높아도 특정 실제 보컬의 잘못된 점수가 File 오탐을 만들 수 있으므로, CPS가 높다는 이유로 Presence 오류 분석을 생략하지 않습니다.

CPU에서 데이터 취득·라벨 검수·구간 고정·용량 점검·업로드를 끝낸 후 기존 workspace를 재사용합니다. 최초에는 소량 파일로 모델 로딩과 파일당 시간을 실측하고, 그 결과로 전체 추출 비용과 절대 종료 시각을 정합니다. 추출한 특징과 구간 예측은 오디오·모델·전처리 해시에 묶어 재사용합니다. 결합식 비교는 저장된 예측으로 CPU에서 수행하고, head 후보는 같은 캐시로 비교합니다. 가설을 판정하지 못한 채 같은 대규모 추출을 반복하지 않습니다. 새로운 실행의 bootstrap을 먼저 업로드하고, 실행 중에는 5분 간격 확인 후 결과 다운로드·무결성 검증을 마치면 계산을 중지합니다.

최신 B_full1696은 1696개 원본 중 음악 라벨을 쓸 수 있는 1216개로 음악 head를 학습했고, 음성 자료 480개는 음악 라벨에서 제외했습니다.
