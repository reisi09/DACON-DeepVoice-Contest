# S2 8:1:1 데이터 분할

현재 작업 범위는 데이터 분할만이다. 기존 S2 원본 음악 풀 918개와 분할 seed `split41`을 유지하고, 원본 그룹 비율을 6:2:2에서 8:1:1로 바꿨다. 같은 원본·아티스트 그룹은 둘로 나누지 않는다.

| 구분 | 원본 그룹 | 파일 | Real | Fake |
|---|---:|---:|---:|---:|
| train | 49 | 630 | 49 | 581 |
| validation | 6 | 88 | 6 | 82 |
| test | 6 | 90 | 6 | 84 |

AudioLDM은 train·validation에서 제외했다. 나머지 110개는 AudioLDM 제외 기록으로 남겼다. 그룹별 파일 수 차이와 제외 조건 때문에 파일 수의 비율은 정확히 80:10:10이 아니다. 원본 그룹 배정이 8:1:1이다.

분할 간 ID·파일 SHA-256·PCM SHA-256·원본 그룹 중복이 없고, 제외된 자료까지 합쳐 원본 풀 전체를 설명하는지 확인했다. test는 기존 S2 test 190개의 부분집합이다. 독립 test 그룹과 Real 음악이 각각 6개뿐이므로 정밀도에는 한계가 있다.

분할 원본은 `split_manifest.json`이며, 프로젝트 루트에서 `.venv/bin/python prepare_s2_811.py`로 다시 생성할 수 있다. 이 명령은 분할 파일만 만들며 학습을 실행하지 않는다.

진행 중 어시스턴트가 요청 범위를 잘못 해석해 H100 재학습을 시작했다. 사용자의 정정 직후 워크스페이스를 정지했고, VESSL stopped/standby 상태와 자동 점검 PAUSED를 확인했다. 재학습 결과는 채택하지 않으며, 기존 제출 ZIP을 변경하지 않았다. 종료 기록은 `workspace_run.json`에 남겼다. 학습은 별도 지시 전까지 재개하지 않는다.
