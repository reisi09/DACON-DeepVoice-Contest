# FakeMusicCaps acquisition bank

Status: **complete and stopped**. The selected bank contains **512 prompt groups × 5 generators = 2,560 original WAVs**, totaling **1,652,410,368 original-audio bytes**. Bank files occupy **1,666,541,118 bytes**, below the 1,750,000,000-byte allocation. All 2,560 selected members passed original CRC, retained-byte SHA-256, native decode and full canonical mono16k decode checks; quality flags and known locked/prior prompt overlap are zero. Exact source/native/canonical hashes are each unique across all 2,560 rows. No GPU or training was started.

The original authors' [Zenodo v2 dataset record](https://zenodo.org/records/15063698) and [record API](https://zenodo.org/api/records/15063698) explicitly license the dataset under **CC BY-NC 4.0**. Attribution: Luca Comanducci, Paolo Bestagini and Stefano Tubaro; FakeMusicCaps v2 (2025), DOI 10.5281/zenodo.15063698. The public archive is 12,889,873,014 bytes with official MD5 `db418dc95ab7dc378a55f29d6021fd66`.

The archive central directory contains 5,521 original MusicCaps IDs, each with exactly five generated WAV siblings: AudioLDM2, MusicGen medium, MusicLDM, Mustango and Stable Audio Open. Each generator contributes 5,521 WAVs. The 64 MusicCaps prompts already used by the frozen SunoCaps confirmation panel all occur here; their 320 generated siblings remain excluded from future training. The selected 512 groups exclude every recorded prior/evaluation MusicCaps ID. Selection used a deterministic hash order among locally recoverable quality-passing AudioLDM2 originals and retained all five generator siblings; no model score was used. No MusicCaps human YouTube audio is acquired.

Selected original WAV bytes are retained as individual files, with each manifest row preserving the original archive member locator. No resampling, denoising, volume normalization or clipping removal is applied to the retained bank. The initial recovery removed owned partials/chunks totaling 1,028,514,289 bytes only after SHA-256 receipts and successful recovery checks; official metadata and the remote central directory remain retained. Inspection records native sample rate, channels, duration, peak, RMS and near-full-scale fraction. Silence, nonfinite PCM, short files, duration mismatch and exact duplicate content are flagged. Source labels do not establish independently reviewed perceptual quality or voice authenticity/presence.

Both raw-file SHA-256 and native-PCM SHA-256 are recorded. A separate full mono16k float32 SHA-256 follows the existing `v2_data.decode_audio(limit_seconds=None)` FFmpeg contract. A real PCM24/44.1kHz WAV check confirmed identical path-versus-stream canonical hashes. Each selected member is checked against the original ZIP CRC and receives a local SHA-256. The official whole-archive MD5 is preserved as provenance but **was not verified**, because the full archive was cancelled. The retained group-lock snapshot determines evaluation exclusions; no scores or new model predictions are used.

The official [generation repository](https://github.com/polimi-ispl/FakeMusicCaps/tree/cd80fa3363c761f6b129c0a7a7a57257d75f11c5) identifies caption-based generation. Its AudioLDM2 code names the `audioldm2-music` output folder while the released ZIP names it `audioldm2`; the bank preserves the ZIP family name and does not infer a per-file checkpoint attestation. Near-duplicate audio, generator pretraining overlap and undocumented cross-corpus reference aliases remain outside exact-hash guarantees.

Machine-readable evidence: `fakemusiccaps_source_review.json`, `fakemusiccaps_receipt.json`, `fakemusiccaps_sources.csv` and `fakemusiccaps_final_audit.json`. Cleanup receipts preserve hashes for removed owned download fragments. The full-archive download entry point is disabled.

All original files are mono at 16kHz. Source durations are retained: 1,536 files are 10.0 seconds, 512 are 10.18 seconds and 512 are 10.242 seconds. The final audit confirms no owned partial files or acquisition/curl processes remain. After the shared request gate was introduced, the observed maximum was 65 starts in any 60 seconds, below the 90/minute bound; earlier HTTP 429 responses triggered a pause and client pacing adjustment. The collection does not establish independent listening quality, absence of every near duplicate, or downstream model improvement.
