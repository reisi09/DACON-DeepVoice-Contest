## 가창 자료 검사

CtrSVDD dev ZIP의 41,728개 오디오를 모두 읽어 CRC, SHA-256, 전체 디코딩과 품질 기준을 검사했습니다. 26,849개가 편입 후보입니다. SVC A06–A08의 14,835개는 입력 가수·녹음 부모가 불명확해 보류했습니다. 추가 44개는 0.075–0.2375초로 0.25초 하한보다 짧았습니다. 파일 손상으로 확인된 것은 아닙니다.

프로토콜에는 있지만 ZIP에는 없는 real 1,897개(Kiritan 525, JVS-MuSiC 1,372)는 공식 배포 제외 자료입니다. 새로 다운로드한 것처럼 세지 않았습니다. 출처는 [공식 저장소](https://github.com/SVDDChallenge/CtrSVDD_Utils)와 [공식 논문](https://arxiv.org/html/2406.02438v2)입니다. 논문 2.2.2에 따른 SVC 입력 가수 문제 때문에 목표 가수 ID만으로 SVC 분할을 확정하지 않았습니다.

## 학습 전에 해결할 문제

- 실제 가창 real은 M4Singer 가수 4명입니다. train 2명, val 1명, test 1명으로 나뉩니다. 서로 다른 가수가 같은 곡·악보를 사용한 관계까지 확인한 상태는 아닙니다.
- CtrSVDD A03/A04는 가수 그룹이 1개여서 이번 분할에서는 val에만 있고 train/test에는 없습니다. 그대로 일반적인 동일 분포 검증으로 해석하면 안 됩니다. 추가 train 원본과 부모 관계를 확인한 뒤 다시 구성하거나, 명시적인 미학습 생성기 진단 항목으로 분리해야 합니다.
- 총 27개 출처·생성기·라벨·분할 조합이 비어 있습니다. 검사기가 0행 조합도 보고하도록 수정했습니다. 작은 음악 생성기 출처의 val/test는 1–3행에 불과한 경우도 있습니다. 상세 목록은 `audit.json`에 있습니다.
- fake voice 9,270행 중 가창 자료는 8,675행이고 기존 ASV 음성은 595행입니다. 총량을 늘렸지만 가창 쪽으로 편중됐습니다. 미완료 음성 자료를 실제로 편입한 뒤 발화/가창 구성비를 다시 확인해야 합니다.
- 음악의 출처만 사용한 AUC는 val/test 모두 약 0.9565, 길이만 사용한 AUC는 약 0.9020/0.9247입니다. 모델 성능이 아니라 정답을 추측할 수 있는 데이터 편향 지표입니다. 이 수치를 낮추려고 test를 반복 조정하지 않습니다.
- test 3,374행 중 807행은 과거 개발 노출 표시가 있습니다. 독립 test라고 부르지 않습니다.
- C1/C2의 real-sham 대조군과 구간 정렬, 음악 내 음성 라벨의 unknown mask, 새 loader/notebook 연결, A100 실제 VRAM·16시간 처리량 검증이 남았습니다. 이 구성으로 학습 가능하다고 결론 내리지 않았습니다.

확인된 가수·부모·해시 그룹의 분할 간 중복은 없으며, 의도적으로 부모 누수와 unknown mask 오류를 넣었을 때 검사기가 거부했습니다. 이는 아직 밝혀지지 않은 곡·악보 관계까지 누수가 없다는 뜻은 아닙니다.
