# 추가 수집분을 합친 70/15/15 분할

2026-09-19 16:06 KST 입력 스냅샷으로 만든 **잠정 분할**이다. 7,144개 제한을 없앴으며 기존 원본과 추가 수집분을 실제 CSV로 통합했다. GPU 학습은 시작하지 않았다. 수집 중인 음성·가창 자료와 부분 편집 대조군 검사가 남아 있어 `training_ready=false`다.

## 실제 구성

| 분할 | real | fake | 합계 |
|---|---:|---:|---:|
| train | 4,615 | 4,615 | 9,230 |
| val | 989 | 989 | 1,978 |
| test | 989 | 989 | 1,978 |
| 전체 | 6,593 | 6,593 | 13,186 |

전체 17,684행을 통합했다. 이 가운데 새로 수집한 오디오는 1,642개이며, 기존 자료는 16,042개다. 검사를 통과한 후보 16,879개에서 real/fake 1:1로 가능한 최대 규모인 13,186개를 선별했다. 남은 3,693개는 클래스 균형을 위한 예비 목록으로 보존했다. 원본 파일을 삭제하거나 복제하지 않았다.

새 학습 후보에는 **SonicMaster로 마스터링한 실제 음악 465개와 Lyria 생성 음악 320개**, 총 785개가 들어갔다. 새 파일이 적게 들어간 이유는 7,144개 상한이 아니라 부모·이용조건 확인, 부분 편집 대조군 준비, 클래스 균형 조건 때문이다. 검사를 통과한 Lyria 500개 중 180개는 예비 목록에 있다. B1 500개 중 35개는 부모의 MTG 메타데이터 또는 이용조건 연결이 확인되지 않아 보류했다.

| 유형 | train real | train fake | val real | val fake | test real | test fake |
|---|---:|---:|---:|---:|---:|---:|
| 음성 | 3,234 | 1,365 | 692 | 263 | 694 | 372 |
| 음악 | 1,381 | 3,250 | 297 | 726 | 295 | 617 |

전체 real/fake 균형과 음성·음악 각각의 균형은 다르다. 가짜 음성 2,000개는 모두 보존했다. 해당 음성은 연결된 화자 그룹이 네 개라서 음성만 따로 정확한 70/15/15를 맞추려면 일부를 버려야 한다. 이번에는 그룹을 유지하고 네 그룹을 train 두 개, val 한 개, test 한 개에 배정했다. 전체 분할은 반올림 오차 내에서 70/15/15다.

## 검사 결과와 남은 문제

- 선택한 13,186개 오디오의 원본 SHA-256을 모두 다시 확인했다. 추가 수집 1,642개는 전체 디코딩, 유한 값·무음 검사, 사이드카 해시·부모 연결 검사를 거쳤다. 음질 청취나 성분별 정답 검증을 끝냈다는 뜻은 아니다.
- 알려진 곡·아티스트·원본 발화·파생물·해시의 연결 그룹이 분할을 가로지르지 않는다. 실제 manifest에 의도적으로 부모 누수를 넣으면 검사기가 거부하는 것도 확인했다. 미상 성분의 mask를 1로 바꾼 경우도 거부했다.
- C1 500개와 C2 142개는 진짜 음악에 같은 편집을 적용한 대조군이 없어 진단용으로 보류했다. 이 중 353개는 기록된 구간 끝이 디코딩한 길이를 0.15초 넘게 벗어난다. C1 메타데이터 길이와 실제 길이의 차이는 중앙값 약 0.156초, 최대 약 0.246초다. 시간 라벨을 임의로 잘라서 정답으로 쓰지 않았다.
- 새 음성·가창 아카이브는 아직 이 분할에 편입하지 않았다. PartialSpoof dev 원본은 이후 다운로드 검증을 마쳤지만, 부모 연결·부분 조작 라벨·real 대조군 검사가 남았다. 나머지 수집도 계속 진행 중이다.
- 음악의 보컬 존재·진위 정답은 미상인 경우 그대로 마스킹했다. 음악 보컬 오탐 문제를 해결할 완전한 혼합 성분 정답이 확보됐다고 주장할 수 없다.
- 음악에서 출처만 사용한 AUC는 val 0.9672, test 0.9612다. 길이만 사용한 AUC도 각각 0.8718, 0.8725다. 학습 모델의 점수가 아니라 데이터 편향 진단이다. 새 데이터가 들어갔어도 출처·길이 편향이 충분히 해소되지 않았다. 일부 Echoes 생성기는 val/test에 1~몇 개뿐이어서 개별 성능 추정이 불안정하다.
- 과거 개발 노출이 기록된 행은 train 7,221개, val 1,507개, test 1,660개다. 그룹을 통한 노출도 포함한다. **이 test는 독립 평가셋이 아니다.** 성능을 보기 전에 분할했지만, 이번 검사에서 test의 라벨·분포를 확인했다.

1차 분할은 전체 클래스 균형만 맞추면서 test의 가짜 음성이 60개로 줄었다. 이를 발견해 희소한 음성 fake와 음악 real을 먼저 보존하는 조건을 추가했다. 이후 결과가 이 폴더다. 1차 파일은 `../reconstructed_bank_20260919_initial/`에 보존했다. 모델 성능이나 리더보드 점수를 보고 분할을 고른 것이 아니다.

## 파일과 재현

- `combined_catalog.csv`: 기존·신규 전체 목록, 선택 여부, 보류 사유, 부모 그룹, 알려진 정답의 mask.
- `selected.csv`: 실제 선별한 13,186개.
- `train.csv`, `val.csv`, `test.csv`: 새 분할 파일.
- `composition.csv`: 출처·생성기·라벨·분할별 수량.
- `pending_collection.csv`: 스냅샷 당시 아직 다운로드 검증을 마치지 않은 파일.
- `verification.json`: 수량, 해시, 선별 조건, 과거 노출, 학습 전 미해결 항목.
- `audit.json`: 실제 분할 파일 일치, 누수·미상 라벨 거부 검사, 희소 유형과 편향 진단.

```sh
.venv/bin/python reconstruct_candidate_bank.py --output results/reconstructed_bank_NEXT
.venv/bin/python verify_reconstructed_bank.py --output results/reconstructed_bank_NEXT
```

완료된 스냅샷 경로는 덮어쓰지 않는다. 다운로드가 더 완료되면 별도 경로에 새 분할을 만들어 비교한다. 이 스크립트는 현재 검증된 HAIM 추가분을 편입하며, ASVspoof5·CtrSVDD·VocalSet·PartialSpoof의 학습 편입은 원본별 연결·라벨 검사를 구현한 뒤 진행해야 한다.

기존 H100 노트북과 학습 진입점은 이 잠정 분할로 바꾸지 않았다. 현재 로더는 train/val만 지원하고 H100을 검사한다. test 격리와 mask 적용, A100 전환, 약 16시간 내 처리량·VRAM 실측을 확인한 뒤 학습에 연결한다. 모델 구조는 HTDemucs base, frozen MERT330M layer12 WindowMIL, DF-Arena fc5, PANNs를 유지한다.

MTG 원본·아티스트 연결 근거: https://github.com/MTG/mtg-jamendo-dataset . 내려받은 고정 revision과 원본 해시는 `../candidate_acquisition_20260919/metadata/mtg_sources.json`에 기록했다. Claude Opus 5 검토는 `../candidate_acquisition_20260919/claude_reconstruction_review.txt`에 보존했으며, 실제 파일 검사 결과와 구별했다.

최신 HAIM 2,000개 전체를 반영한 스냅샷은 `../reconstructed_bank_20260919_haim_complete/README.md`다. 앞선 수량·노출·진단은 각 작성 시점의 기록이며, 최신 결과는 이 스냅샷을 따른다.
