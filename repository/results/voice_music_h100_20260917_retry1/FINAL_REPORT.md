## 실험별 판단

1. **동일 길이·음량 대조군:** 기존 1번 결과를 재사용했다. dev의 실제 음성 4개에서 DF-Arena vocals 평균 가짜 확률은 음성 단독 0.0242에서 0 dB 혼합 0.5645로 높아졌다. 원본 음성만 사용하면 가짜 음성을 놓치는 경우도 있어, 분리기를 바로 제거할 근거는 아니다.
2. **AntiDeepfake:** 전체 추론은 93.12초였다. DF와 Anti 평균은 dev 혼합 8개에서 File EER를 두 혼합 조건 모두 25%에서 0%로 낮췄다. 그러나 test 혼합 8개에서는 -6 dB 조건이 0%에서 25%로 악화했고, 0 dB는 50%로 같았다. 기본 test 21개에서는 24.04%에서 13.94%로 개선했다. 패널마다 결과가 엇갈려 일반화 개선으로 확정할 수 없다.
3. **음성 residual head:** 504개·7명 화자 자료를 내부 학습·검증으로 나눠 seed 41, 최대 30 epochs·patience 8 조건에서 학습하고 checkpoint를 저장했다. dev/test의 보고된 File·Voice EER는 M330 기준과 같았다. 가창 라벨이 없어 배포 조건도 충족하지 못했다. 현재 결과로 추가 학습을 우선할 이유는 없다.
4. **새 음악 추가:** NSynth를 제외한 대조군 1,596행과 새 음악 52곡을 더한 군을 각각 seed 41·17 epochs로 학습했다. 실제 optimizer update는 425회와 442회였다. 새 음악 dev 16곡에서 Music EER는 기본 조건 31.67%로 같고, 4초는 36.67%→31.67%, 전화는 31.67%→18.33%로 개선했다. MP3는 31.67%→36.67%로 악화했다. 기본 dev Music EER는 기존 M330의 18.33%보다 나쁘므로 새 head를 교체 후보로 확정하지 않는다.
5. **독립 calibration·File 결합:** 음성 8개와 음악 21개 calibration 자료로 양의 기울기 Platt 계수를 고정했다. dev MP3 전체 24개에서 File EER는 미보정 DF+Anti 평균 29.29%에서 보정 후 12.14%로 개선했다. test 0 dB 혼합은 50%→25%로 개선했으나 -6 dB는 기준 M330보다 나쁜 25%였다. 보정 후 max와 noisy-OR는 보고된 dev/test EER가 같아, noisy-OR를 우선할 실증 근거는 없다.
6. **음질 검사·조건부 seed:** MP3 Music EER가 악화해 사전 조건을 통과하지 못했다. seed 42·43 추가 학습은 실행하지 않았다. 선택 기록은 test 평가 전에 저장됐다.

## 다음 실험의 우선순위

현재 M330을 기준으로 유지하고, DF+Anti의 혼합음 개선과 calibration 효과를 더 많은 독립 화자·음악 배경에서 다시 확인하는 편이 타당하다. 특히 test의 -6 dB 악화를 만든 파일과 배경 보컬을 먼저 청취 검수해야 한다. 음악 head를 크게 학습하기 전에는 MP3 악화와 M330 대비 기본 성능 열세를 해결해야 한다. 이번 자료를 추가 선택에 쓰면 이미 확인한 진단 자료로 취급하고, 새 홀드아웃을 별도로 마련해야 한다.

독립 그룹은 106개로 원천 300개 기준 미달이다. 음성 패널은 이전에 공개한 진단 자료이며, 음성 청취 검수·가창 검증이 끝나지 않았다. FMA/SONICS 출처 편향도 남아 있다. 여기의 EER는 작은 로컬 패널 결과다. 공식 점수, 리더보드 개선, 배포 개선은 확인하지 않았다.
