1. 원천 목록과 약정서를 첨부한다.
2. 재배포가 불가한 원천(MusicCaps, FortisAVQA)은 파일 대신 공식 출처와 파일 목록으로 제출할 수 있는지 주최 측에 문의한다.
3. 필요하면 해당 행을 빼고 재학습한 모델로 재현성을 입증한다.
