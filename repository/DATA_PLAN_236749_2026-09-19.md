- Voice EER은 VOICE_PRESENT=1 파일에서만, Music EER은 MUSIC_PRESENT=1 파일에서만 계산되므로 부재 성분의 FAKE 라벨은 마스크(손실 제외)가 맞다. 공란은 지금처럼 "근거 없음"으로 두되, **근거가 있는 공란(SONICS 보컬 등)은 채운다.**

### 2.2 지름길 차단 원칙

1. **원천 내부에 두 라벨**: 가능한 모든 원천 계열에서 real·fake 쌍을 만든다 — HAIM(A1 real vs A2 fake, B1 real vs B2~B4 fake), Jamendo(JamendoMaxCaps·MTG 실제 vs ACE-Step/Lyria 가짜, 같은 카탈로그 장르 분포), ASVspoof(같은 화자 bona fide vs spoof), Zeroth(실제 vs 같은 전사문으로 만든 TTS·같은 발화의 VC), VocalSet/CSD(실제 가창 vs RVC 변환), Echoes ATA(FMA 원곡 vs 그 원곡 조건 생성물).
2. **길이·코덱·채널·라우드니스는 라벨과 독립 추첨**: 파일마다 길이 d~histogram(4~10 s 30%, 10~30 s 40%, 30~60 s 30%), 컨테이너·비트레이트·전화 체인·모노/스테레오·게인을 라벨·원천을 보지 않고 같은 분포에서 뽑는다. 원본이 짧은 원천(FMC 10 s, ASVspoof 3 s)은 상대 라벨에도 같은 길이 히스토그램을 강제한다(4.3절).
3. **분할은 그룹 단위**: 화자(음성), 아티스트(음악), 캡션/프롬프트/참조곡(생성물), 혼합물의 부모 전부(합성)로 연결 성분을 만들고, 성분 하나는 한 분할에만 둔다.
4. **생성기 홀드아웃**: 가짜 계열마다 최소 1개 생성기는 학습에서 완전히 뺀다. 목표 지표는 "미학습 생성기 EER"이지 "같은 생성기 EER"이 아니다.
5. **양보다 다양성**: 프론트엔드가 동결 SSL(MERT/XLS-R)이라 같은 생성기에서 1,000개 더 넣는 것보다 새 생성기 100개가 낫다. 이것이 16k → 10k 축소의 근거다.

## 6. 전처리·정규화 파이프라인 (라벨 독립 추첨)

1. **디코드 → 16 kHz(soxr HQ)**: 테스트가 "전부 16 kHz 표준화"이므로 학습도 동일. 원본 SR은 manifest에만 남긴다.
2. **길이 크롭**: 파일마다 d를 히스토그램(4~10 s 30% / 10~30 s 40% / 30~60 s 30%)에서 라벨·원천을 보지 않고 추첨. 시작 오프셋은 무작위(도입부 편향 방지, 노래는 보컬 구간 포함되도록 Demucs 보컬 에너지 상위 구간 우선). 원본 < d이면 전체 사용, 원본 < 4 s(ASVspoof 다수)는 같은 그룹 발화를 이어붙임. **원본이 짧은 원천이 있는 셀은 상대 라벨에도 같은 d 분포를 강제**(FMC 10 s ↔ Jamendo 4~10 s 크롭 100개).
3. **라우드니스**: −23 LUFS 정규화 후 ±4 dB 무작위 게인, 피크 −1 dBFS 리미터. (FMC RMS 0.07~0.4 편차 같은 음량 지름길 제거)
4. **채널**: 스테레오 원본은 50% 유지 / 50% 다운믹스, 모노 원본은 70% 모노 / 30% 2채널 복제. 테스트의 "모노/스테레오 혼재"와 정합.
5. **코덱 체인(파일당 1개, 라벨 독립)**: WAV PCM16 35%, FLAC 20%, MP3 64/96/128/192 kbps 30%, Opus 32~48 kbps → WAV 5%, **텔레포니 체인 10%**(음성 포함 유형 15%, 음악 단독 5%). 최종 컨테이너는 MP3/WAV/FLAC로만 저장. 체인 문자열을 manifest에 기록.
6. **보컬 존재 검증(음악 원천 전부)**: HTDemucs 보컬 스템 RMS 비율 r(3 s 창 최대값). r ≥ 0.25 → VOICE_PRESENT=1, r ≤ 0.05 → 0, 사이는 마스크. 원천별 30개 청취로 임계값 보정 후 고정. SONICS·B6·ACE-Step 가사·songgen·diffrhythm은 메타데이터(가사 존재)와 r이 일치할 때만 1, 불일치는 마스크.
7. **중복 제거**: 정확 PCM 해시(기존) + 크로마프린트/CLAP 임베딩 코사인 > 0.97 근사 중복(특히 HAIM A1 MTG ↔ JamendoMaxCaps, OpenMIC ↔ FMA, Echoes ATA 참조곡 ↔ FMA, SunoCaps ↔ SONICS).
8. **지름길 프로브(학습 전 게이트)**: (a) 메타데이터만(길이·컨테이너·비트레이트·채널·LUFS·원본 SR)으로 FILE_FAKE 로지스틱 회귀 5-fold AUC ≤ 0.60, (b) 유형별 real/fake 길이 분포 KS p > 0.05, (c) 코덱 분포 카이제곱 p > 0.05, (d) 첫 0.5 s 무음 비율·클리핑 비율 차이 없음. 실패하면 2~5 재추첨.

## 8. 혼합(mixed) 합성 규칙 (900개)

- 성분 풀: 음성 = 3.2절 실제/가짜(한국어 ≥ 50%), 음악 = 3.3절 실제/가짜 무보컬. 성분의 `group_id`를 모두 상속(`parent_ids`), 분할은 부모 전부가 같은 분할일 때만 생성.

- 라벨 조합: real+real 400, fakeV+realM 200, realV+fakeM 200, fake+fake 100. FILE_FAKE = OR, 성분 FAKE는 성분 출처대로.
- 부분 생성 스플라이스 100개(위 quota 안에서): 실제 음성 안에 같은 화자 TTS/VC 1~3 s 삽입 → VOICE_FAKE=1, FILE_FAKE=1. HAIM C1/C2가 음악 쪽 순차 사례를 담당.
- 8 s 고정 레거시 합성물은 폐기. 새 합성물도 6절의 길이·코덱 추첨을 동일하게 통과.

## 9. 검증 계획과 실험 순서 (제출 3회/일 × 10일 = 30회)

측정 지표: 공식 산식 그대로(argmin |FPR−FNR|, drop_intermediate=False) + **원천별·생성기별 EER 행렬** + 미학습 생성기 EER(locked).

| ID | 1요인 실험 | 데이터 변경만 | 판단 기준 |
|---|---|---|---|
| E0 | 재라벨 + 길이·코덱 정규화만(기존 5,059) | R6·R7 해결 | 리더보드 Voice/File 축 이동 확인. 이 한 번이 기준선 |
| E1 | + 한국어 음성 real/fake + ASVspoof2021 전화 | R4·R5 | Voice EER, File EER |
| E2 | + HAIM 확장(A1·Lyria·B2~B4·B6~B9·C) | R1·R8 | Music EER, 미학습 생성기 EER |
| E3 | + "AI 후처리된 REAL" 300개(B1 100, EnCodec/DAC 복원 100, DeepFilterNet 노이즈 제거 100) | 운영진 규칙 정합 | 점수 상승 시 채택, 하락 시 전량 제거 |
| E4 | + 합성 혼합 900 | 혼합 유형 | File EER, 존재 AUC |
| E5 | 텔레포니 비율 10% vs 25% | 채널 강건성 | Voice EER |
| E6 | 자체 생성 TTS/VC 추가 | 최신 생성기 | 미학습 생성기 EER |

- 로컬(dev/locked) 점수와 리더보드 점수의 상관을 매 제출 갱신. 상관 < 0.5면 locked 구성을 의심한다(테스트 분포 추정이 아니라 locked의 대표성 점검).
- 원천별 EER 행렬에서 특정 원천 EER ≈ 0이고 다른 원천 ≈ 50%면 그 원천에 지름길이 남아 있는 것 → 6.8 프로브 재실행.
