# 일반 ChatGPT 채팅에 넘길 작업

이 패키지는 일반 ChatGPT 채팅에서 분석·설계·코드 작성을 진행하고, 반환된 결과를 로컬 Codex에서 검사하기 위한 입력이다. Work 작업 생성이나 GPU 실행은 필요하지 않다. 모델 선택은 사용자가 UI에서 한다. 특정 모델명이나 도구가 해당 채팅에 제공되는지는 이 패키지가 보장하지 않는다.

## 사용 순서

1. 일반 ChatGPT 새 채팅을 열고 원하는 모델·추론 수준을 선택한다.
2. `DACON_Chat_Stacking_Input.zip` 하나를 첨부한다.
3. `01_MAIN_PROMPT.md`의 본문 전체를 첫 메시지에 붙여 넣는다. ZIP 해제 도구가 없다면 ZIP 속 문서를 읽었다고 주장하지 말고, 필요한 파일을 구체적으로 요청하도록 프롬프트에 명시했다.
4. 한 번에 완료하지 못하면 `05_FOLLOWUP_PROMPTS.md`의 이어가기 문구를 사용한다. 새 채팅보다 같은 채팅을 이어가는 편이 작업 중복을 줄인다.
5. 최종 `DACON_Stacking_Return.zip`과 `RETURN_REPORT.md`를 내려받아 Codex에 첨부한다. 실행되지 않은 항목은 그대로 남겨 둔다.

## ChatGPT에서 먼저 끝낼 일

| 작업 | 요구 산출물 |
|---|---|
| 현재 모델·데이터·캐시 분석 | 코드 위치를 근거로 한 구조 설명, 캐시에서 얻을 수 있는 피처와 추가 추출 피처 구분 |
| 독립 평가 및 누수 방지 설계 | 데이터 계획, split 정책, base-model 노출 이력 검사, 학습·평가 절차 |
| 피처 기반 스태킹 구현 | 캐시 변환, Logistic Regression·ExtraTrees·XGBoost 비교, 피처 묶음 비교 |
| 추론 통합 준비 | 최종 File 점수만 교체하는 파일별 독립 추론 경로, 저장·로드 |
| CPU 검증 | 실제 소형 head·캐시 재계산, 누수 거부, 저장 후 결과 일치, 순서·부분집합 독립성 |
| 실행 안내 | CPU 실험과 나중의 GPU 추출을 분리한 명령, 최소 패치·변경 목록·미검증 항목 |

## Codex에서 할 일

반환 파일을 기준 소스·해시와 비교하고, 논리·데이터 누수·수치·CPU 통합 검사를 수행한다. 필요한 수정만 반영한다. 코드가 있다는 이유로 성능 향상을 인정하지 않는다. 새 오디오 확보·GPU 추출·본 실험·제출은 이 인수인계 작업에 포함되지 않는다.

## 포함 범위

- 현재 제출 소스와 학습 당시 소스, 데이터 목록 및 출처·노출 메타데이터.
- 기존 val/test의 실제 예측 CSV. 과거 노출된 진단 자료이며 새 OOF나 독립 holdout이 아니다.
- 작은 음악·음성 head 가중치 6개와 실제 특징 캐시 10개. CPU 경로 확인용이며 성능 판정용 표본이 아니다.
- 기존 실험 기록과 공식 규정의 로컬 보관 문서. 규정·라이선스는 새 실행 전에 공식 원문을 다시 확인한다.
- 대형 encoder 가중치, 실제 오디오, 전체 9,504개 특징 캐시, 로그인 정보·원격 실행 설정은 제외했다.

이 입력 ZIP은 실행 가능한 전체 제출 모델이 아니다. 새 성능 결과나 학습 완료를 나타내지도 않는다.
