# DACON 오디오 위조 탐지 프로젝트

현재 채택한 모델의 소스, 데이터 목록, 학습·평가 기록을 정리한 인수인계 패키지입니다. 기준은 **2026-09-20에 완료를 확인한 Existing9504 H100 실험과 그 결과로 만든 최종 제출 코드**입니다.

먼저 [프로젝트 설명](PROJECT.md)을 읽고, [데이터 설명](DATASETS.md)과 [코드 안내](CODE_MAP.md)를 참고하면 됩니다.

| 경로 | 내용 |
|---|---|
| `PROJECT.md` | 목적, 현재 구조, 학습 방식, 결과와 한계 |
| `DATASETS.md` | 데이터 목록의 의미, 출처별 구성, 분할 정책, 라벨·마스크 |
| `CODE_MAP.md` | 현재 실행 코드와 과거 참고 코드의 위치, 재현에 필요한 파일 |
| `data/` | 읽기 쉽게 정리한 선택·후보 목록, 출처별 집계, 실제 학습 실행 목록 |
| `evidence/` | 검증·평가 수치, 체크포인트 선택 기록, 배치 측정 기록 |
| `repository/` | 기존 통합 소스의 전체 파일과 원본 데이터 메타데이터 |
| `PACKAGE_MANIFEST.json` | ZIP 내부 파일별 SHA-256과 출처 |

**실제 오디오, 모델 가중치, 특징 캐시, 가상환경은 포함하지 않았습니다.** CSV의 오디오 경로는 파일의 위치를 기록한 문자열입니다. 이 ZIP만으로 학습이나 모델 추론이 바로 실행되지는 않습니다. 필요한 외부 파일과 실행 조건은 `CODE_MAP.md`에 적었습니다.

`repository/`에는 과거 실험 소스도 보존했습니다. 현재 구조를 확인할 때는 `CODE_MAP.md`의 최신 경로를 우선 사용하세요. 과거 README의 “실행 전”, “아직 완료되지 않음” 같은 상태 설명은 작성 당시 기록이며, 현재 상태는 이 패키지의 `PROJECT.md`와 완료 증거를 기준으로 읽어야 합니다.
